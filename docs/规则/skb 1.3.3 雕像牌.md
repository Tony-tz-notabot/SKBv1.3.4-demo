# SKB 雕像牌
牌库中以下10种每种雕像（雕塑）牌五种花色（白绿蓝橙红）各有1张

 1.巫师雕像
摸2张牌

2.狼人雕像
距离2。选择一个目标，吸其2盾或1血（自己选择）。以其实际收受到的伤害作为你的回复量。

3.珺之精灵雕像
距离不限。选择一个目标，拆除其一张牌（注意是牌）

4.盗贼雕像
距离1。选择一个目标，获取其一张牌。

5.狂战士雕像
本回合可攻击次数+1（可攻击次数和攻击次数是同一个东西，不区分）

6.圣骑士雕像
只有当他人打出雕像牌时可以使用（包括回合内外），打出后使被响应的雕像牌无效；不能响应特殊牌或其他牌。圣骑士雕像也可被再打出的圣骑士雕像无效，嵌套按后进先出结算，最后判断原雕像是否生效。

7.牧师雕像
展示牌堆顶x张牌（x为在场且未被淘汰的人数）。从你开始逆时针，每名未淘汰角色各获得一次选择机会，可以拿走一张，也可以不拿；超时视为不拿。所有人完成一次选择后，未被拿走的牌进入弃牌堆，不会再次轮到发起者选择。

8.骑士雕像
指定一名角色进行决斗。从他开始，他和你轮流弃置杀，直至有不弃置（没杀无法弃置了或主动不弃置了）的一方视为失败。决斗胜利方可选择一把已装备且有效的武器，对失败方发起一次不可闪、不可近战格挡、无视防具的攻击，不支付杀或可攻击次数。若选择的武器的最远射程仍小于双方距离，则用最远射程的一档攻击。蓄力武器以蓄力0状态的临时副本结算，不影响原武器的蓄力进度。

9.刺客雕像
对场上除你外的所有人发起一次飞镖攻击，距离不限。
飞镖：远程伤害2。

10.工程师雕像
距离不限。指定一名角色，在其判定区内放置工程师雕像。
其判定阶段判定：绿：收到3点血量伤害并移除工程师雕像。
否则移到下一名玩家判定区内。
