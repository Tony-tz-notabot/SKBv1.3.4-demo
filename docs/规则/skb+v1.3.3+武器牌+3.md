W-54 撒币枪

颜色：红
类型：远程/场地
属性：

· 常规：[1:1]
· 特殊：若有金币，可以打出一张金币，不用【杀】且不消耗攻击次数：[4：场地3；判定：(绿、蓝、橙、红：附加伤害2)]

注释：


撒币枪：常规模式下为距离1伤害1的远程武器，输出极低。特殊模式下需消耗一张金币，变为距离4场地伤害3，且判定绿/蓝/橙/红时附加伤害2（总伤5）。场地伤害不可闪/格挡、无视防具。

金币：基础牌，也是撒币枪的特殊消耗。进水的箱子可以生成不进入手牌、必须立即选择用途并自动打出的临时金币。撒币枪判定的绿、蓝、橙、红四种成功颜色必须保留，用于判中及暴击判断。


注释

千本：根据距离自动选择档位（距离2时1×2，距离1时1×3）。每次攻击的多段伤害全部结算完毕后进行一次判定，决定是否触发追加效果（毒1×2）。



破碎的剑刃/剑柄：两把白色武器，合成为重铸的圣剑。圣剑为场地2×2伤害，无视防具、不可闪/格挡。

重生十字章：占用一个武器槽，不可用于攻击。装备后在濒死时可选择使用。使用后回满血量，然后失去此牌。

冰霜之鹰/火焰之鹰 → 冰与火之鹰：冰与火之鹰为1张基础牌（非合成专属），也可通过合成获得。远程连击2段各1伤，命中后判定橙追加火×2，判定绿冰一回合。橙和绿互斥，一次判定只触发一个。

雪狐玫瑰金：1×3×2 = 单发伤害1 × 散弹3段 × 连击2段 = 6段各1伤。受“散弹增加”天赋影响时散弹段数+1（变1×4×2=8段），受“连击增加”天赋影响时连击段数+1（变1×3×3=9段），两者可叠加。

玄冥：方式一的初态固定为火形态，首次攻击为火，第二次自动切换为冰，第三次切回火，以此类推。切换为锁定机制，无法手动保留在某形态。方式一和方式二每次攻击时任选其一。

火龙步枪：方式一为场地火伤，无视防具。方式二为激光，不可近战格挡，命中判定红/橙追加火伤。每次攻击时任选其一。
