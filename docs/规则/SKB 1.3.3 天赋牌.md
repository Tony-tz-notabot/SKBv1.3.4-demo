天赋通用规则

1. 同名天赋不可叠加。同一角色不能同时装备两张或以上名称相同的天赋牌或与初始天赋重复。试图装备同名天赋时，该操作非法：失去该手牌并摸1张牌，不视为装备或弃置。
2. 初始天赋不可移除。角色初始天赋不占天赋槽位，且不可以任何方式被拆除、弃置或替换。
3. 天赋效果随装备状态生效。天赋牌提供的增益效果仅在该天赋存在于装备区时生效。天赋牌因任何原因离开装备区（包括被替换、拆除、弃置等）时，其提供的增益效果立即消失。由该天赋增加的血量上限、护盾上限等属性，在天赋移除时相应扣除。
