M-11 百变怪
颜色：红
坐骑类型：±坐骑（占+和-两个槽位）
属性：基础防御距离+0，基础进攻距离-0
附加效果：每当你拥有火盾或毒盾，进攻距离额外-1；每当你拥有冰盾或电盾，防御距离额外+1。以上效果可叠加。

注释：

关于“+”与“-”坐骑：+坐骑的效果为“防御距离+X”，即其他角色对你进行操作（攻击、技能、卡牌效果等）时，计算双方距离需加上X。-坐骑的效果为“进攻距离-Y”，即你对其他角色进行操作时，计算双方距离需减去Y。两者计算互不干扰。

关于槽位占用：±坐骑同时占用+坐骑和-坐骑两个槽位，即使某侧数值为0也占用该侧槽位。装备±坐骑时，若原有对应槽位已有坐骑，则被替换进入弃牌堆。

关于百变怪的动态加成：百变怪的效果随装备者当前拥有的天赋实时变动。检查时机为距离计算时，以当时装备区中火盾/毒盾/冰盾/电盾的存在与否为准。若同时拥有火盾和毒盾，进攻距离累计-2；同时拥有冰盾和电盾，防御距离累计+2。天赋被移除或新获得时，距离加成立即更新。初始天赋（如骑士的蓝盾、炼金术士的毒盾、机器人的电盾、工程师的火盾）同样计入百变怪的判断。


补充一条通用规则：

距离计算下限：经过所有修正后的有效距离最低为0（即不能为负）。若进攻距离修正后<0，视为0；若防御距离修正后<0，视为0。
