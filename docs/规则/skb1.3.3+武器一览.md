通用规则

蓄力：蓄力武器可选择指定武器但不指定目标，消耗攻击次数打出【杀】，使蓄力进度+1。使用已蓄力武器攻击后按蓄力进度攻击，然后蓄力进度消失。蓄力进度跟随武器（武器转移时保留，进弃牌堆消失）。

连击/散弹：一次攻击包含多次同参数伤害段（如 1×3），目标只需响应一次。出闪或合法近战格挡均抵消整次攻击的全部伤害段，攻击视为未命中。分别受“连击增加”和“散弹增加”天赋加成。

合成：在手牌区或装备区的武器若满足条件可在出牌阶段合成。合成不视为“弃置”。

第三武器：不占常规武器槽，在装备区单独显示，同时只能装备一把第三武器。

手刀：仅当所有常规武器槽均为空时可用。近战伤害2，距离1。手刀不是主动可选的攻击方式，而是无武器时的被动状态。

颜色：颜色不代表强度。同效果的不同颜色武器为不同颜色构筑提供选项。颜色等级仅用于重铸熔炉等特定效果。
等于当前有效距离的最小一档。

数量：未标注张数的武器默认牌库1张。标注“0张”的为合成获得，不计入牌库。
