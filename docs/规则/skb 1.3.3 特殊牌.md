颜色：绿
数量：3张
打出后，场上除你外所有人需以任何方式出【闪】，最后未出闪的x人每人受到x点感电伤害。

SP-03 羊叫兽
颜色：橙
数量：0张（由网瘾少年和网瘾少女合成）
打出后进入阶段一：场上除你外所有人依次处理是否以任何方式打出【闪】；所有需响应者均处理完毕后，未出闪者受到2点感电伤害，并在本回合之后时间内无法以任何方式出闪。阶段一全部结算完成后进入阶段二，触发网瘾少年的完整效果。

修改目标护盾至0（若其有盾），或修改其血量至1（若其无盾）。

SP-05 重铸熔炉
颜色：白
数量：2张
弃置一张已装备的武器牌，从牌堆顶逐张翻开至出现一张颜色等级高于等于被弃武器的武器牌，或已翻出8张牌为止。从翻开的牌中选择一张武器牌获取，翻开的其余牌进入弃牌堆。若翻完8张仍未出现符合条件的武器牌，则从已翻出的所有牌中选择一张武器牌获取（若有）；若8张中无任何武器牌，则无牌可获取。

SP-06 起源熔炉

弃置一张已装备的武器牌，根据被弃武器的颜色摸牌：白或绿摸2张，蓝或橙摸3张，红摸4张。

SP-07 号角小队
颜色：橙
数量：1张
打出后至你下个准备阶段开始前，所有人实际打出【杀】发起一般武器攻击时不消耗可攻击次数。此牌不增加或恢复可攻击次数；明确写明消耗可攻击次数发动的技能、武器模式或装备能力仍照常消耗，不能借此反复发动。

SP-08 拆迁大队
颜色：橙
数量：1张
从当前回合玩家开始逆时针，每名玩家可选择弃置最多一张已装备的武器牌。所有人操作完毕后，每名玩家将各自装备区中剩余的所有已装备武器牌，全部交给下家（逆时针方向），同时从上家获得其传来的武器牌。若获得武器后超出自身武器槽位上限，需立即弃置超出数量的武器牌。有三持天赋的上家若武器数量超过下家槽位上限，下家必须弃置超出部分。

SP-09 超级大宝贝儿
颜色：红
数量：1张
打出后进入你的判定区。下回合你的判定阶段触发。触发时，场上包括你在内的所有人需打出【闪】（破除防具），未出闪者受到3点血量伤害。然后场上除你外的所有人（不论出闪与否）受到毒火伤害1×2。

SP-11 鲜血祭坛
颜色：红
数量：1张
打出后，血量上限-2，当前血量-2，一轮内拥有铁盾1。下回合开始，你永久获得“鲜血诅咒”效果。
鲜血诅咒：每回合你首次使用【杀】指定攻击目标后，对该目标额外造成2点场地伤害。

注释：

关于“以任何方式出闪”：包括手牌中的【闪】、防具提供的出闪效果、技能提供的出闪效果（如刺客信条、游侠翻滚等），以及在网瘾少年/少女/羊叫兽/超级大宝贝儿效果要求下任何可产生闪避效果的手段。

关于“颜色等级”：五色从低到高为白 < 绿 < 蓝 < 橙 < 红。

关于合成（羊叫兽）：需在手牌中同时持有网瘾少年和网瘾少女，出牌阶段将两者移入弃牌堆，从牌库外获得羊叫兽。合成不消耗可攻击次数。

关于“破除防具”：该次要求出闪时，目标不能使用防具的闪避效果来响应，只能通过手牌中的【闪】或技能出闪。

关于“本回合之后时间内”：指当前回合出牌阶段的剩余时间及该回合后续阶段。若在该回合出牌阶段打出，则封锁持续到该回合结束。

关于伤害来源：所有特殊牌造成的伤害，伤害来源均为打出该特殊牌的角色。

关于羊叫兽与网瘾少年的结算连续性：羊叫兽打出后，先执行自身效果，再立即执行网瘾少年的完整效果，中间不插入其他结算。两部分各自独立统计未出闪人数x。

关于超级大宝贝儿的延时特性：打出后进入判定区，属于延时型效果。在该牌所在判定阶段触发前，若该牌被拆除（如珺之精灵雕像），则效果不触发，牌进入弃牌堆。

关于拆迁大队的槽位冲突：三持天赋提供3个武器槽位，常规为2个。轮换时以各自当前槽位上限为准。超出上限的武器由玩家自行选择弃置。

关于奉献池：此牌为彩蛋牌，仅消耗资源并显示随机语句，不产生任何游戏效果。语句选择无实际影响。

关于鲜血诅咒的触发时机：“指定目标后”在目标响应攻击之前触发。因此鲜血诅咒的2点场地伤害先于武器攻击结算，全部伤害结算完毕后再统一判断濒死。
