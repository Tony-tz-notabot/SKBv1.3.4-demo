核心机制备注

一、防具的通用限制

破除防具：当攻击或效果带有“破除防具”属性（包括场地伤害自带）时，所有防具的响应/锁定/主动效果均无法触发，防具在此次攻击中视为不存在。

二、箱子

箱子先于铁盾生效。结算顺序：伤害即将造成 → 箱子抵消（若耐久>0）→ 铁盾减免 → 扣盾/扣血。箱子为锁定技，有耐久时强制触发，无法选择不发动。

三、杀无效 vs 攻击发起

核心区分：盾牌（A-04）和圆盾（A-08）的效果是使【杀】本身无效，而非攻击发起后的闪避或伤害减免。

结算流程：

1. 打出【杀】
2. 检查防具：若【杀】被无效 → 流程终止，攻击未发起
3. 若未被无效 → 攻击正式发起，蓄力进度清除
4. 目标响应

资源消耗：【杀】被无效时，【杀】牌和可攻击次数均已消耗，不可返还。

蓄力进度：因攻击未发起，蓄力进度保留。区分如下：

防具 效果类型 蓄力进度
盾牌 杀无效 保留
圆盾 杀无效 保留
双截棍/光剑土豪金 视作出闪 清除
幽灵王冠 攻击无效 清除
箱子/精致法杖 伤害减免 清除

四、圆盾

全局全场：指定颜色的【杀】对场上所有角色均无效，包括队友和对手。

信息不公开：指定颜色仅使用者知晓，其他玩家不被告知。对手或队友打出被封锁颜色的【杀】时才会发现攻击无效。

五、幽灵王冠

触发条件：出牌阶段结束时，本回合未进行任何武器攻击且未进行任何蓄力操作。蓄力视作攻击准备，无法触发此效果。

六、斩首者

打出【杀】视作近战格挡，遵循近战格挡规则，仅能格挡远程攻击。配合“近反”天赋可反弹远程攻击。
