# 特殊生命层、血量下限与钢铁破浪者号

## 一、拳击柱额外生命层

拳击柱开局初始化`punchingBag.extraHp=12`。该层不可回复；普通、真实和血量伤害先扣该层，再在同一伤害段内溢出到普通护盾/血量。护盾专属伤害只扣护盾。

伤害结果新增`actualSpecialLayerLoss`，并计入`actualDamage`、收到伤害与攻击目标汇总；因此后续惯性反击可以累计特殊层、护盾和普通血量的全部实际损失。

## 二、血量下限

- 所有角色开局具有权威`healthFloor`，默认-1；超界者初始为3。
- 扣血时实际血量最低到当前下限，`actualHpLoss`只记录真实扣除量；拟议伤害和最终伤害可以大于实际损失。
- 血量下限不替代濒死判断：实际血量仍在0及以下时进入濒死。
- 超界者的平行穿梭有效时，仅在其自己的结束阶段开始将下限减1，最低-1；他人结束阶段不改变。

## 三、钢铁破浪者号

救援全部失败后仍依次发出死亡前、死亡和淘汰前事件。若钢铁破浪者号仍在持有者BOSS槽，淘汰被替换为：

- `lifeState=deadNotEliminated`；
- 移除血量、护盾条并解除濒死栈；
- 标记非锁定能力失效；
- 后续自己的回合计数归零；
- 恢复外围攻击，不进行胜负判定。

死亡发生所在回合不计数。之后每次自己的回合开始计1；第2个后续自己的结束阶段开始时立即淘汰。死亡后主动丢弃或替换该BOSS牌非法；外部拆除等失牌移动合法，但与卡牌离场原子触发立即淘汰。

死亡未淘汰者既有的“攻击仍可命中并产生零实际损失收到伤害事件”沿用文档61，不触发按实际伤害获益。
