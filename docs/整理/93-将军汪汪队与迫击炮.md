# 将军汪汪队与迫击炮

状态：角色规则R049、R050服务端实现记录。

## 一、汪汪队

任意角色实际进入结束阶段正文时，若将军仍在场且存活，服务器自动创建一次距离不限的多目标脚本攻击。目标为所有在场且未淘汰角色，包括将军本人；顺序从当前回合角色开始按1→2→3→4循环，不能由攻击来源座位重新排序。

每个目标获得独立的近战1点护盾伤害攻击画像，分别开放合法响应、分别结算伤害与濒死；上一目标完整结束后才继续下一目标。被其他效果跳过的结束阶段不启动，已淘汰的将军不启动。脚本攻击使用冻结`character-rules.json`中的攻击方式、伤害类型和数值。

为此，通用复合脚本攻击增加显式`preserveTargetOrder`入口：只有调用者已经按权威时间轴排好目标时使用，普通多目标攻击仍保留原有按攻击者逆时针排序。

## 二、迫击炮

将军在自己的出牌阶段且技能冷却就绪时获得`offer:skill.general.mortar`。命令校验对局、修订、玩家、提示和当前报价并支持幂等；成功后挂起原出牌窗口，从将军本人开始按逆时针把所有在场角色排入即时伤害队列。

每名目标受到3点场地普通直接伤害。即时伤害原语现可显式携带`attackType=field`，保证场地相关免疫/修正使用正确语义，同时仍不构成攻击或开放普通闪/格挡。调度器每次只执行一个目标；目标进入濒死时先完成救援、死亡、淘汰或救回，再执行下一目标。队列末尾只恢复一次原出牌窗口。

CD=2按通用定义实现为使用后需经过3个自己的准备阶段才重新报价：标记初值3，每个自己的准备阶段递减，归零即恢复。使用时记录冷却开始，准备阶段记录冷却推进。

## 三、验证

测试覆盖其他角色结束阶段触发、当前回合角色起始的逆时针顺序、四目标独立响应与护盾伤害、将军本人合法目标、跳过阶段/将军淘汰不触发；迫击炮覆盖报价、幂等提交、四目标队列、场地普通伤害、濒死中断后保留后三目标、出牌窗口恢复及第三个准备阶段恢复CD。服务端55个测试文件、236项测试及TypeScript构建全部通过。
