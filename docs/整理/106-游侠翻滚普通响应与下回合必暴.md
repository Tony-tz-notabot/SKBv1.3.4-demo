# 游侠翻滚普通响应与下回合必暴

状态：R014 服务端严格执行闭环。

## 一、补齐的执行边界

- 普通攻击响应窗口现在复用统一特殊出牌报价；游侠需要出【闪】时，可选择一张橙色手牌作为“翻滚”响应。
- 提交时重新校验角色技能、牌仍在本人手牌、印刷颜色仍为橙色以及响应窗口仍有效；失败不移动牌、不写领域事件。
- 成功后该牌以响应方式进入弃牌堆，当前整次攻击视为未命中，并仅登记“下个自己的回合”待生效标记。
- 待生效标记不会令游侠当前回合的攻击暴击。到游侠下个回合开始时，标记转换为覆盖所有以【杀】发起攻击的必定暴击授权。
- 授权采用 `retainUntilExpiry`，因此不会被该回合第一次合法攻击消费；该回合每次以【杀】发起的攻击均必定暴击。
- 游侠该回合结束时统一删除授权；即使阶段被跳过，也仍按回合结束节点删除。

## 二、统一路径

- 特殊【闪】报价与牌色转换继续由 `specialCardPlay.ts` 负责。
- 普通武器攻击响应由 `response.ts` 接入相同报价和提交原语，不再只识别实体【闪】。
- 下回合开始和回合结束分别复用正式时间轴的 `onSpecialPlayOwnerTurnStart` 与 `expireGuaranteedCriticalAtTurnEnd`。
- 攻击提交继续复用通用必暴授权消费器；翻滚授权保留到到期，不为每次攻击重复创建状态。

## 三、验证

新增独立行为测试覆盖：普通攻击窗口橙牌报价、成功响应后整次未命中、当前回合不提前获得必暴、下个自己回合开始武装、同回合两次【杀】攻击均必暴及回合结束清除。
