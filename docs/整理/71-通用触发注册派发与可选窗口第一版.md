# 通用触发注册、派发与可选窗口第一版

状态：基础解释器完成；事件生产者统一后处理桥待下一阶段接入。

## 规则注册

- 从冻结的通用、角色、武器、非BOSS与BOSS规则文件递归提取 `triggers/trigger`；当前真实结构共26条。
- 每条触发保留来源文件、JSON路径、家族、事件、时机、范围、费用、效果及稳定触发ID。
- 系统优先级按 DSL 固定为合法性、替代、防止、锁定修改、可选修改、普通触发、清理；同级不同角色按当前回合角色起逆时针排序。
- 同角色同优先级存在多个触发时标记为需要角色排序，不擅自按代码顺序代替玩家选择。

## 激活与筛选

- 初始天赋直接按角色激活；装备牌只在对应公开生效区域激活；普通装备失效会关闭装备牌触发但不关闭初始天赋。
- BOSS触发只从BOSS槽实例产生；牌实例与控制者均进入候选事实。
- 已实现阶段、角色、目标、来源、状态、攻击类型、伤害正数和失去装备等公共筛选。
- 未实现的筛选字段严格失败关闭，不能把未知条件默认为真。

## 效果派发

- 无选择效果已支持：回血、回盾、摸牌、创建直接伤害、施加状态、增减标记、消费次数和顺序容器。
- 每次执行前重新匹配来源和条件；未知操作抛错且原状态保持不变。
- 直接伤害进入 `immediate.damagePipeline`，继续由第70号实现的统一伤害与濒死执行器消费。

## 可选触发

- 无费用、无二次选牌/目标的可选触发可打开 `optionalTrigger` 报价，明确提供发动与放弃。
- 命令校验游戏、修订、提示、优先权和报价；相同 `commandId` 返回首次结果。
- 超时复用放弃命令路径。带费用或选择效果的触发明确路由到后续专门选择窗口。
