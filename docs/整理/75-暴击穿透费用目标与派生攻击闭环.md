# 暴击穿透费用、目标与派生攻击闭环

状态：冻结规则中的暴击穿透触发已形成完整权威窗口与派生攻击链。

## 触发与报价

- 监听暴击武器攻击的 `attack.hit`；原攻击带 `criticalPenetrationFollowup` 标签时严格不再触发。
- 可选窗口同时报价控制者手牌中的合法【杀】和按原武器射程可选的角色。
- 新目标必须区别于原攻击已有目标；仍使用标准“在场角色”、距离及目标合法性计算。
- 没有可支付【杀】或没有另一合法目标时只允许放弃；超时按可选有利操作规则放弃。

## 提交边界

- 发动时重新匹配触发、重新计算手牌【杀】和目标；权限、提示、修订及报价任一失效均拒绝且不支付。
- 【杀】从手牌移入结算区并产生 `card.played` 与 `cost.paid`，整个操作不修改可攻击次数。
- 读取原攻击已经锁定的 `weaponRef`、`modeId`、射程、攻击类型、响应策略、伤害段和判定规格；不读取当前预选，也不能切换武器。
- 派生攻击不继承原攻击已经得到的暴击或必定暴击结果；其后按该武器自身规则重新处理判定。

## 队列与时序

- 派生攻击写入原攻击的 `afterAttackQueue`，不抢在原目标伤害段、攻击后效果或濒死流程之前启动。
- 原攻击完整 `attack.resolved` 后，现有攻击生命周期按深度优先规则启动派生攻击，并只在最外层全部结束后恢复出牌窗口。
- 派生攻击带 `criticalPenetrationFollowup` 标签，因此即使再次暴击命中也不会递归生成暴击穿透。

## 【杀】无效

- 支付后、加入攻击队列前继续执行盾牌/圆盾颜色无效检查。
- 若被无效，【杀】费用不退且立即进入弃牌堆，不创建派生攻击；圆盾首次匹配仍按既有规则公开颜色。
- 场地攻击等既有无视防具边界继续交给统一【杀】无效计算。
