# 状态、持续期、判定与武器判定效果第一版

## 一、实现范围

- 状态实例进入唯一权威状态，保存叠加策略、来源、优先级、持续期引用和结构化元数据。
- 冰冻、电击按配置创建持续期；即使对应阶段因该状态或其他原因被跳过，也在规定的阶段后边界到期。
- 普通判定使用真实牌堆顶牌；判定牌进入结算区，最终进入弃牌堆。
- 替换判定先将旧判定牌弃置，再翻开新的真实牌。
- 武器判定结果中的 `createDamage` 与 `applyStatus` 已进入统一执行器，先执行判定结果，再继续原攻击伤害段。

## 二、判定干预窗口

- 真实判定牌翻开后，从当前回合角色开始逆时针依次取得干预优先权。
- 连续四名角色放弃后，服务器自动结算判定；响应命令具有幂等结果缓存。
- 判定牌被替换后，旧放弃记录全部清空，优先权重新从当前回合角色开始。
- 超时属于可选操作，按放弃处理。
- 萨满“逆天改命”属于翻牌前替代普通判定的指定结果，不与本版翻牌后的替换窗口混为一谈，留在下一小段接入。

## 三、指定结果与通用暴击

- “必定暴击”遇到具有暴击判定的武器时，服务器只报价该判定规则中标记为成功的颜色；攻击者必须选择其一，不翻牌、不消耗牌堆。
- 萨满“逆天改命”在翻牌前开放响应：轮到萨满优先权时可打出两张同色手牌，随后由萨满指定五色之一；该流程同样不产生真实判定牌。
- “逆天改命”使用标记到萨满下个准备阶段才重置，跨轮次不会提前恢复。
- 无判定武器暴击时，每个 `isAdditional=false` 的伤害段 `amount + 1`；`repeat` 不变，附加伤害段不变。
- 指定结果命令、干预命令均校验提示、优先权、修订号和报价，重复 `commandId` 返回原幂等结果。

## 四、关键不变量

- 客户端只能提交干预意图或放弃，不能提交随机翻牌结果。
- 判定实例同时保留真实牌引用、印刷颜色和最终颜色。
- 判中只标记该攻击为暴击并执行该颜色的武器正文效果；附加伤害不接受通用暴击加成。
- 未知的判定效果操作明确拒绝，不静默跳过。

- TypeScript 构建通过。
