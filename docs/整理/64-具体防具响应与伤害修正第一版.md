# 具体防具响应与伤害修正第一版

## 一、范围

本阶段把已正式裁定的具体防具接入服务器权威攻击管线，覆盖双截棍、黄金激光剑、斩首者、箱子、精致法杖、鬼王冠与陷阱箱子。盾牌、圆盾见文档63。

## 二、统一执行位置

1. 攻击提交并支付费用后，先处理“攻击无效”。
2. 未无效的攻击按目标依次开启响应；防具判定和斩首者均属于响应层，成功时抵消该目标承受的整次攻击。
3. 命中后，每个正数伤害段先处理箱子等整段防止，再处理精致法杖的数值修正，随后进入铁盾、特殊生命层、护盾和血量路由。
4. `ignoreArmor`统一令上述防具效果不生效，但不移除装备。

## 三、具体语义

- 双截棍：每名目标每次攻击至多尝试一次；判定橙色则视为闪避，失败后仍可继续响应。
- 黄金激光剑：与双截棍相同，但成功色为蓝色或橙色。
- 斩首者：使用手牌中的【杀】格挡一次远程攻击，抵消整次攻击，不消耗攻击次数。
- 箱子：初始耐久3；每个正数伤害段消耗1耐久并防止整段，耐久归零后在该段处理完成时进入弃牌堆；同一次连击的后续段可正常造成伤害。
- 精致法杖：每个装备者轮次第一次被远程非激光攻击命中时消耗额度；该次攻击第一个正数伤害段减2（最低0）。即使此次命中只有0伤，也消耗额度；下个准备阶段刷新。
- 鬼王冠：装备者出牌阶段结束时，若本回合既未提交武器攻击，也未执行蓄力，则生效至其下个准备阶段前；期间针对他的远程非激光攻击整次无效。手刀不计为武器攻击。
- 陷阱箱子：初始耐久3；每防止一个正数伤害段消耗1耐久，并登记一次由装备者对该段来源发起的距离不限、远程2反击。所有登记均等待原攻击及其濒死流程完成后，再按登记顺序作为标准攻击结算；反击可正常响应，不支付【杀】或攻击次数。耐久归零后保留到最后一次由该次耗尽产生的反击结束，再回到牌库外。

## 四、实现边界

- 防具实例、耐久、每轮额度和鬼王冠持续期均保存在权威状态中，客户端只显示投影结果。
- 判定防具复用真实判定牌和萨满判定前干预窗口。
- 通用攻击收尾现区分本攻击产生的子反击与上层尚未执行的同级反击；子反击完整结束后才恢复上层队列，最外层全部结束后只恢复一次原出牌窗口。
