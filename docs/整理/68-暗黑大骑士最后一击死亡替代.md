# 暗黑大骑士最后一击死亡替代

状态：服务端第一版实现完成。对应 B032、B033。

## 实现边界

- 持续期内、至少持有1枚黑剑且暗黑大骑士处于激活状态时，死亡暂时替换为 `deadNotEliminated`，清除血量与护盾条，但暂不淘汰。
- 原攻击及其已登记子攻击完成后才打开 `darkKnightFinalStrike` 可选窗口；合法目标为所有未淘汰、未离场的在场角色。
- 每次确认先消耗1枚黑剑，再提交距离不限、近战普通伤害3、破除防具、不可近战格挡的标准攻击；不支付【杀】和攻击次数。
- 每次攻击的响应、伤害及目标濒死完整结束后，才请求下一枚黑剑。嵌套产生多个最后一击时，优先处理刚完成攻击的目标，再返回外层链。
- 主动放弃或超时均清空余下黑剑并淘汰；没有余剑时自动淘汰。整个链完成后仅恢复一次最外层出牌窗口。
- BOSS在目标选择阶段离场时，清空黑剑、取消未提交攻击并立即淘汰；攻击已经提交时，该攻击继续，完成后再淘汰。

## 协议与幂等

- `DarkKnightFinalStrikeSession` 提供修订、提示、优先权、报价和目标二次校验，并缓存相同 `commandId` 的首次结果。
- 超时复用同一命令入口，以放弃报价执行，不存在随机选目标的旁路。
