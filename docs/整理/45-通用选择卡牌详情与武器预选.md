# 通用选择、卡牌详情与武器预选

## 一、通用选择输入

报价面板现已覆盖 `SelectionSpec` 的全部种类：

- `cards`：从服务器给定的合法牌引用中选择；
- `targets`：从服务器给定的合法角色引用中选择；
- `option`：选择服务器提供的离散选项；
- `number`：选择服务器提供的合法数字；
- `color`：选择服务器提供的合法颜色；
- `mode`：选择服务器提供的武器或能力模式；
- `confirm`：确认或取消。

所有类型统一遵守 `min/max/options/legalRefs`。客户端只负责收集和检查结构完整性，服务器提交时仍须重新验证；切换报价或收到新修订会清空旧选择。

## 二、卡牌详情

手牌和公开卡牌可通过“详情”按钮或右键打开详情侧栏。侧栏显示服务器投影提供的：

- 原始主图、名称、类别和印刷颜色；
- 规则摘要和核心数值；
- 当前有效性、蓄力、耐久与冷却；
- 服务器动态徽标。

详情层不读取Markdown，不解释DSL，不自行推导动态规则。

## 三、武器预选

点击本地角色装备中的武器会提交 `SET_PRESELECTION`，并以服务器下一份 `privateView.preselectedWeaponSlot` 常亮显示。该操作不消耗攻击次数、杀或其他规则费用。点击其他玩家装备不会改变预选。

当前协议只投影已有装备实例，尚不能渲染明确的空武器槽。因此“可预选空槽”和“仅所有武器槽为空时空槽代表手刀”将在下一阶段扩充槽位投影后实现，不能由客户端根据装备数组猜测。

## 四、禁用提示

`disabledHints`按对象引用提供禁用原因。卡牌显示失效视觉和提示标记，操作面板列出服务器消息键。客户端不因本地判断而把未报价对象标成“非法”，防止泄露隐藏信息。
