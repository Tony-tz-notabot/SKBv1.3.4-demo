# 攻击外直接伤害与即时计划执行器

状态：服务端第一版实现完成。

## 统一边界

- `immediate.damagePipeline` 计划不再只登记：自动调度器会在稳定边界优先消费，再继续阶段时间轴。
- 直接伤害不伪装成攻击，不开放普通闪避响应，也不产生普通攻击命中/攻击后收益。
- 段级执行与攻击伤害共用同一核心：元素免疫、无敌、箱子/陷阱箱子、铁盾、拳击柱额外生命层、护盾/血量路由、蓝盾不溢出、血量下限和死亡未淘汰收到伤害语义保持一致。
- 直接伤害使血量降至0及以下时进入统一濒死栈；自动调度器随后打开普通濒死救援窗口。
- 目标已经淘汰或离场时计划安全取消并记录原因，不产生部分伤害。
- 陷阱箱子因直接伤害登记的反击会进入标准攻击上下文，继续走响应、伤害与濒死管线。

## 接口

- `hasImmediateDamageEffect(state)`
- `executeNextImmediateDamageEffect(state)`
- `applyDirectDamageInTransaction(tx, input)`
