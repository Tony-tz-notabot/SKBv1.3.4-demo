# 炼金术士剧毒药剂与脚本攻击费用闭环

## 主动技能边界

- `skill.alchemist.toxic_reagent`只向当前自己出牌阶段中的存活、在场炼金术士报价，每个自己的出牌阶段限成功使用一次。
- 费用候选严格来自本人手牌，并按`cards.json`的印刷颜色筛选绿色；装备区、判定区及非绿色手牌均不可支付。
- 目标为使用者外当前在场且未淘汰角色，并按实时攻防距离计算限制在距离2内。报价后提交时重新验证费用牌和目标。
- 技能不消耗【杀】或可攻击次数。成功提交后绿色费用牌进入结算区，待整次攻击完成再进入弃牌堆。

## 毒瓶攻击

- 毒瓶复用统一脚本攻击管线，创建单目标、距离2的场地攻击。
- 攻击不可闪、不可近战格挡并无视防具；仍经过标准攻击命中、伤害段、濒死和攻击完成流程。
- 伤害为毒属性普通伤害`1×2`。
- 攻击与伤害段均显式保存`ignoreTalentModifiers`，因此炼金术士自身毒盾不会把次数增加到3，其他天赋加段也不能修改毒瓶。
- 攻击结束后只恢复一次原出牌窗口；同阶段再次报价为空。

## 通用脚本攻击扩展

- 脚本攻击现可保存`costCardRefs`，用于非【杀】费用牌的统一结算后清理。
- `attack.costs.paid`区分`killCardRefs`与一般`costCardRefs`，避免把绿色费用牌误记为【杀】。
- 可选`resumePlayDeadlineAt`和`ignoreTalentModifiers`进入攻击快照，供后续角色主动攻击复用。
