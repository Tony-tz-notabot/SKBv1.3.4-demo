# 网瘾双牌特殊出闪与感电伤害闭环

## 共用规则边界

- `SP-01`网瘾少年与`SP-02`网瘾少女由同一执行器处理，分别校验冻结规则中完全相同的效果结构，不再存在名称分支造成的玩法差异。
- 两者均只能在自己的出牌阶段使用；使用后挂起原出牌窗口并进入结算区。
- 响应者为使用者外当前在场且未淘汰角色，按使用者之后的逆时针顺序逐人处理，但必须收齐全部响应后才创建伤害。

## 特殊出闪

- 实体【闪】、游侠翻滚、刺客同色双牌出闪均复用统一特殊出牌模块。
- 该请求允许防具：双截棍判橙、光剑土豪金判蓝/橙。防具判定成功才计为已出闪；失败后返回同一响应者继续选择，且同一防具在本次请求中不可重复尝试。
- 特殊出闪不是攻击，不开放近战格挡，也不产生攻击命中/未命中事件。
- 响应超时按可选有利操作处理为放弃。

## 伤害与恢复

- 收齐响应后锁定未响应人数`x`；`x=0`时不创建伤害。
- `x>0`时，对每名未响应者依次创建`x`点直接普通感电伤害并叠加1层感电标记；每个目标的濒死流程完整结束后才继续下一目标。
- 所有伤害与叠标记完成后，特殊牌进入弃牌堆并恢复原使用者的出牌窗口；随后按总纲 13.6 在整次效果结束后统一检查感电标记结算（先多人后单人，可循环）。

## 验证

- 覆盖两张牌同流程、全员先响应、`x`计数、实体闪、防具判定成功、判定失败后继续响应、防具不可重复及出牌窗口恢复。
- 接入后服务端全量回归63个测试文件、279项测试通过；随后新增防具失败专项用例通过，当前总测试数280项。TypeScript构建通过。
