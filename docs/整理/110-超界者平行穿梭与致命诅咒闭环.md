# 超界者平行穿梭与致命诅咒闭环

## 实现范围

- R021保持既有实现：平行穿梭有效时，仅在超界者自己的结束阶段开始令血量下限减1，最低为-1。
- R022接入攻击与攻击外即时伤害的统一伤害次数管线。以超界者为来源或目标的每个正数伤害次数分别进行真实判定；绿/蓝仅令当前次数无效，其他次数继续结算；0伤不判定。
- R023提供修订绑定、幂等的主动技能报价与提交。必须在自己的出牌阶段、仍有正数攻击次数、整局未用过且个人所有区域合计至少有配置数量的牌。

## 致命诅咒时间线

- 发动时弃置所有可主动弃置的个人牌；普通BOSS牌计入持有数量，但依正式裁定不可主动弃置，钢铁破浪者号例外。
- 标记一名当前在场角色后，超界者立即离场并永久关闭平行穿梭。离场不是死亡或淘汰，既有距离和胜负特例不变。
- 后续第一次、第二次轮到自己时，各阶段均在阶段开始边界被跳过。
- 第三次轮到自己时直接进入结束阶段。结束阶段开始的第一个角色专属钩子先检查标记目标；仍在场则把盾、血量和血量下限修改为配置值。无论目标是否仍在场，超界者随后回场、设置血盾并摸配置数量的牌，之后才处理其他结束阶段效果。

## 软编码与验证

最低牌数、离场回合数、回归血盾/摸牌数以及处决修改值集中在`rulesets/v1.3.4/settings.json`，并同步更新冻结哈希。行为测试覆盖发动门槛、不可弃BOSS、三次自己回合、目标失效、攻击多段独立判定、攻击外判定和0伤不判定。

全量结果：服务端74个测试文件、316项测试通过，TypeScript生产构建通过。
