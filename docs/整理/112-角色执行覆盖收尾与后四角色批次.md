# 角色执行覆盖收尾与后四角色批次

状态：服务端 25 名角色的首轮权威执行覆盖已闭环。

## 本批实现

- R025：矿工所有已存在的回合外主动出牌入口统一退出遁地；有攻击/伤害来源时再进入强制拆牌，并在提交时重验来源牌。
- R027—R035：恶魔术士、死灵法师、机器人、刺客、法师的主动技能、命中触发、持续期及独立攻击边界已接入。
- R036—R037：元气弹严格支付两张手牌与一次攻击次数，不支付【杀】；六种有效天赋映射、禁普通/技能闪、判定冰冻及命中拆牌已接入。龟派气功作用于配置化手刀基础值之后。
- R038—R040：吸炸按同次攻击累计实际血量损失；炸弹防御位于铁盾后；准备阶段可选场地逐段引爆，放弃同样清空。
- R041—R044：第一准备阶段强制选择机甲，第4准备开始前或出牌阶段主动退甲；机甲盾为不溢出的特殊生命层；三种非卡牌机甲武器保留【杀】和次数费用。
- R045—R046：既有适应进化整次攻击元素预算继续作为唯一减免路径；藤蔓攻击、CD及命中后的下一摸牌-2接入统一摸牌修正。

## 执行边界

角色能力均通过权威状态、报价/命令或自动时间线触发，不依赖客户端自行结算。普通攻击、响应、判定、伤害段、濒死和出牌窗口恢复继续复用通用管线。角色数值与行为依据冻结 `character-rules.json`、`characters.json` 及版本设置；后续调整不得散落到客户端。
