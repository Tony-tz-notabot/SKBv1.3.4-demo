# SKB 第一轮正式裁定

状态：已由规则作者确认，应并入 v1.3.4 正文。

## 一、版本与文档权威

1. 当前已发布基线为 `v1.3.3 + 补丁1.3.3.2`；正在整理的新版本为 `v1.3.4`。
2. 蓄力、连击/散弹、合成、第三武器全部正式并入 v1.3.4。
3. 冲突优先级采用：最新正式补丁＞当前通用规则＞当前角色/卡牌正文＞正式裁定＞UI 技术文档＞旧规则与草案。裁定应回写正文。

## 二、操作预选与攻击时序

1. 玩家可以在界面中常亮预选一个武器槽；点击其他武器槽切换当前预选。预选和切换本身不是规则行为，不消耗牌、攻击次数或时间次数，也不写公开日志。
2. 发动攻击时不再临时选择武器，而是直接使用当前预选槽中的有效武器。未预选有效武器时，系统提示玩家先选择武器，不进入攻击流程。
3. 空武器槽可以被预选。只有角色所有武器槽均为空时，预选空槽才代表使用手刀；只要任意武器槽中存在武器，空槽就不是有效武器，也不能用来发动手刀攻击。
4. 标准攻击时序为：读取当前预选武器/手刀及攻击方式→选择目标→检查距离和合法性→支付【杀】和攻击次数→检查【杀】无效→攻击正式发起→处理指定目标后/攻击发起时效果→目标响应→判断命中→结算伤害段→攻击后效果→检查濒死。
5. “指定目标后”在支付资源后、目标响应前；鲜血诅咒在此时触发。即使【杀】随后被圆盾无效，只要目标已经合法指定，鲜血诅咒仍触发。
6. 同一目标的多段伤害全部处理后才检查该目标是否濒死。
7. 多目标效果按逆时针逐个目标完整结算：处理第一名目标的全部伤害段并立即完成其濒死流程，再继续下一名目标。不得先对所有目标扣伤、最后统一处理濒死。
8. 濒死流程中产生新的濒死时，优先处理新濒死，再返回原流程。
9. 普通同时触发和多目标效果按逆时针逐项结算；只有明确响应另一个效果的行为使用后进先出。圣骑士雕像嵌套严格后进先出。
10. 被跳过的阶段不发生该阶段开始、阶段内或阶段结束效果；“即将进入阶段”的替代效果可先触发。

## 三、数值

1. 最终手牌上限最低为 0。
2. 主动支付、主动声明的 X、弃置数量和选择数量默认至少为 1；规则计算结果允许为 0。
3. 伤害次数或伤害值经计算成为 0 时，攻击仍可视为命中，但不视为造成伤害，不触发受到伤害或造成伤害类效果。
4. 属性上限降低时，只有超过新上限的当前值被压到新上限；因此降至 0 或以下时正常检查濒死。
5. 有效距离为基础座位距离＋目标防御距离修正＋来源进攻距离修正，最终最低为 0。
6. 淘汰者不占距离；死亡但未淘汰者、断线者、静滞者仍占距离；超界者离场按特例仍占距离。

## 四、牌堆、展示与判定

1. 武器逐项数量优先于错误汇总，现行初始牌库武器按 61 张整理。
2. 展示牌先按效果移动，展示结束后仍留在中央展示区的牌进入弃牌堆。
3. 摸牌、展示、搜索或判定过程中牌堆耗尽，立即用弃牌堆重洗后继续；正在结算/展示的牌不参与重洗。
4. 替换判定时原判定牌先进入弃牌堆，再翻开新的真实牌，并重新开放合法的判定干预。
5. 多人干预判定时，从当前回合玩家开始逆时针取得响应权；有人干预后重新开放一轮，所有人连续放弃后结算。
6. 萨满支付文本改为“两张同色手牌”。“牌”在其他规则中仍包含手牌、装备区、判定区等所有区域，不改变全局定义。
7. 弃牌堆在桌面只以部分重叠方式显示最后进入的几张牌，玩家不可打开完整弃牌堆详细查看。
8. 0 张合成牌用完后返回牌库外，不进入普通弃牌堆，不参与重洗。
9. 一拳（白）是原“一拳”实例的转变形态；离开装备或形态结束时恢复原模板，不作为可普通摸到的独立牌。

## 五、暴击

1. 若武器攻击本身具有暴击判定，则判定成功时该攻击视为暴击，具体暴击结果按该武器文本执行。
2. “必定暴击”对具有暴击判定的武器表现为：攻击者可以直接指定该次暴击判定结果，不再依赖随机翻出的结果。
3. 对没有暴击判定的武器，暴击使每一个非附加伤害段的伤害值＋1。
4. 附加伤害和效果伤害不受暴击加成。
5. 暴击不增加伤害次数，除非具体武器明确说明。

## 六、响应、防御与攻击类型

1. 近战武器格挡合法远程攻击时，抵消该次攻击全部伤害段；连击、散弹等多段攻击也全部抵消，整次攻击视为未命中。
2. 判定型防具失败后，仍可继续用普通【闪】、技能闪或其他合法手段响应。
3. 激光默认可以闪，但不能用近战武器格挡；具体标签可以覆盖。
4. 场地攻击仍是攻击，但默认不可闪、不可近战格挡且无视防具；场地伤害也可以由直接伤害效果产生。若“攻击无效”来源于防具，则因无视防具而不生效；非防具来源的攻击无效、无敌等仍可处理场地攻击。
5. “破除近战”统一改称“不可近战格挡”。
6. 真实伤害无视铁盾和普通减免，但仍能被圣骑士无敌免疫；修改血量/护盾绕过无敌。
7. 蓝盾对多段伤害逐段判断。只有该伤害段开始时目标仍有护盾，才阻止该段的溢出血量伤害。
8. 刺盾改写为令一次近战攻击的第一个正数伤害段－1，最低为 0。
9. 暴击穿透的额外攻击需要再打出一张【杀】，不消耗攻击次数，必须选择另一名角色，不能更换原攻击所用武器；额外攻击不能再次触发暴击穿透。
10. 号角的必定暴击在武器攻击正式发起时消耗；杀被圆盾/盾牌提前无效时不消耗。若一直未使用，到使用者当前回合结束时清除。
11. 来源死亡不取消已经进入结算的攻击、伤害或延时效果；需要来源继续作出选择而来源已淘汰时，取消可选部分或执行规则默认项。

## 七、状态

1. 冰冻不叠加；再次获得时刷新。目标因冰冻或其他原因跳过其应受冰冻影响的出牌阶段后，冰冻均消除。
2. 电击不叠加；再次获得时刷新。目标因电击或其他原因跳过其应受电击影响的摸牌阶段后，电击均消除。
3. 静滞、冰冻、电击等可以同时存在，并在相应阶段一起触发；同名状态仍不叠加。静滞跳过摸牌/出牌阶段时，对应电击/冰冻同时消除。
4. 所有模糊持续期改写为明确阶段节点。
5. 装备区失效不影响 BOSS 槽。
6. 装备失效时耐久、蓄力和状态保留，持续时间照常经过；效果不能发动或触发。
7. 初始天赋不受普通装备区失效影响；明确使角色天赋永久失效的专属规则仍可关闭初始天赋。

## 八、装备、合成与第三武器

1. 装备牌一般都可以在自己的出牌阶段主动丢弃，除非该牌或其他效果明确禁止。主动丢弃后进入该牌规则指定区域，默认进入弃牌堆，并触发失去装备。
2. 合成材料离开装备区时触发失去装备，但不视为弃置。
3. 合成只能在自己的出牌阶段主动进行。满足公式时界面显示合成提示；玩家确认后消耗材料，合成产物加入手牌，不自动装备。玩家之后可以正常装备该牌。
4. 第三武器属于武器。所有泛指“武器”的获取、弃置、拆除、传递、熔炉等效果均包含第三武器；只有明确写“常规武器槽”的规则排除第三武器。
5. 拆迁大队会传递第三武器。若接收者已有第三武器，按第三武器槽冲突规则选择保留一把，其余弃置。
6. 重铸熔炉可以弃置第三武器。
7. 装备区失效时仍可主动丢弃、替换或装备；新装备在状态结束前同样失效。
8. 试图装备同名天赋时，该操作非法；玩家失去该张手牌并摸一张牌。此“失去”不视为成功装备。
9. 蓄力武器在装备区之间转移时保留进度；进入手牌、弃牌堆、牌堆等其他区域时清零；装备失效不清零；攻击正式发起时清零。
10. 蓄力加快可以将一级蓄力需求降至 0，使武器可直接使用该档；不能通过“0 次蓄力”触发蓄力动作效果。

## 九、角色与具体卡牌

1. 圣骑士无敌持续到其下个准备阶段开始前。
2. 拳击柱额外 12 血是优先承伤的特殊生命层。除不能回复外，按正常血量处理；直接修改血量也会一并扣除/作用于该额外血量层，不能绕过它。额外血量耗尽后才处理普通护盾与血量。
3. 超界者离场不等于死亡或淘汰，仍计入己方尚未全灭的胜负判定并占距离；但离场期间不属于“在场角色”。
4. 矿工遁地时远程攻击仍可选择她并支付资源，但攻击对其无效；若矿工主动响应，则按技能规则提前退出遁地。
5. 萨满摸牌替换采用：应摸 N 张时展示 N+2 张并选择 N 张，N 最低为 0。
6. 将军可以成为自己汪汪队攻击的攻击者与目标；指回自己的反弹不重复生成无限反弹。
7. 圆盾每回合出牌阶段限指定一次，持续到使用者下个准备阶段开始前。第一次有【杀】因此无效后，本轮公开显示被封锁的颜色；多个圆盾效果可并存。
8. 骑士雕像攻击不可闪、不可近战格挡、无视防具，但仍可被无敌、免疫和非响应型减免处理。
9. 工程师雕像判定失败时进入逆时针下一名未淘汰玩家判定区末尾，可以循环直到成功、被拆除或游戏结束。
10. 网瘾少年/少女、羊叫兽、超级大宝贝儿的“要求出闪”属于特殊出牌请求，不属于攻击。
11. 鲜血祭坛降低上限和当前血量后立即检查濒死；若死亡则不会在下回合获得鲜血诅咒。
12. 名称统一为“古代元素使”。
13. 除钢铁破浪者号外，BOSS 牌不能被主动替换或主动丢弃。钢铁破浪者号按其专门规则处理主动替换/丢弃。
14. BOSS 使用者被淘汰时，槽内 BOSS 进入弃牌堆且持续效果结束；已经创建的结算继续。
