# SKB v1.3.4非BOSS牌规则正文

状态：整理期非BOSS牌正式稿。本文合并基础牌、防具、天赋、坐骑、雕像、特殊牌原文及P01-P52，是这些牌类的单一规则来源。

## 一、数量与共通规则

本文件所含初始牌共267张：

| 类别 | 模板数 | 初始牌数 |
| --- | ---: | ---: |
| 基础牌 | 5类、22个颜色模板 | 132 |
| 防具 | 9 | 8 |
| 天赋 | 25 | 50 |
| 坐骑 | 11 | 11 |
| 雕像 | 10类×5色 | 50 |
| 特殊牌 | 11 | 16 |

- 陷阱箱、羊叫兽的初始牌数为0，由合成创建；合成实例离场后返回牌库外。
- 除圣骑士雕像和明确响应/延时牌外，雕像、特殊牌在自己的出牌阶段使用，不消耗可攻击次数。
- 非武器资源按“专属图片→类别占位图→通用占位图”加载，不显示破损图标。

## 二、基础牌

| cardId | 名称 | 配置 |
| --- | --- | --- |
| `basic.kill.*` | 杀 | 白、绿、蓝、橙、红各16，共80 |
| `basic.dodge.*` | 闪 | 每色7，共35 |
| `basic.potion.*` | 药水 | 每色2，共10 |
| `basic.horn.*` | 号角 | 每色1，共5 |
| `basic.coin.white/red` | 金币 | 白、红各1，共2 |

- 【杀】：自己的出牌阶段发起一般武器或手刀攻击，默认支付1张杀和1次可攻击次数。
- 【闪】：合法响应窗口打出，默认抵消整次攻击全部伤害段。
- 【药水】：自己的出牌阶段为自己回复2血；任意濒死阶段可为濒死者回复2血。
- 【号角】：自己的出牌阶段选择回复1血，或使本回合下一次正式发起的武器攻击必定暴击；回合结束未用则清除。濒死阶段只能回复1血。
- 【金币】：是基础牌。普通金币可进入手牌；效果生成的临时金币不进入手牌，必须立即选择合法用途，结算、放弃或超时后消失。

### 特殊出闪与结算

网瘾系列先从使用者开始逆时针收集所有响应，再逆时针对未出闪者逐个造成伤害、叠加感电标记并即时处理濒死。该请求不是攻击。羊叫兽两阶段分别支付闪、分别统计，中间不开放无关操作；两阶段造成的感电伤害后各叠加 1 层感电标记。感电伤害结算后按总纲 13.6 在整次效果结束后统一检查感电标记结算。

超级大宝贝儿触发时先收集所有人的响应；逆时针对未出闪者逐个造成3点血量伤害并处理濒死，再逆时针对使用者外仍在场角色逐个造成火毒`1×2`。触发前被拆则不生效。

### 熔炉与武器移动

重铸熔炉先将费用武器放入弃牌堆，再开始展示；牌堆耗尽时正常重洗，因此该武器理论上可被重洗并展示。最多8张，取得1张武器；其余展示牌弃置。

拆迁大队的第一阶段每人可弃0或1把；第二阶段同时传递。接收后常规武器槽或第三武器槽超额时由玩家选择弃置，属于强制选择，超时随机。

### 鲜血诅咒

每个自己的回合第一次合法指定目标并完成【杀】支付时，先对该目标直接造成2点场地伤害，再检查杀无效并继续武器攻击。即使目标因此淘汰，杀与次数仍已消耗，原攻击因目标不再合法而取消。每个自己的回合重新获得一次额度。

### 合成

手牌中SP-01＋SP-02，在自己的出牌阶段确认合成SP-03；材料移入弃牌堆，羊叫兽加入手牌，不自动使用。羊叫兽离场后返回牌库外。
