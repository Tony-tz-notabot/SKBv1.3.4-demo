# 紫爵士魔刃、英刃与准备前攻击实现说明

状态：服务端实现记录。对应B009—B011及冻结BOSS正文。

## 一、无费用脚本攻击入口

新增脚本攻击提交原语，可由BOSS和其他规则效果直接创建攻击上下文。调用者必须明确给出来源、距离、攻击类型、伤害段与自定义判定；该入口不支付【杀】或攻击次数，但提交后统一进入既有响应、命中、伤害、濒死及嵌套攻击管线。

目标在提交事务内重新验证为在场且未淘汰角色。攻击一经提交，即使其来源随后离场，也继续完成。

## 二、魂刀·魔刃

紫爵士持续生效时，每名其他在场角色进入准备阶段前，先创建一次距离不限、近战伤害2的魔刃攻击。触发挂在`phase.before`之后、阶段跳过或替换处理之前，因此即使该角色的准备阶段随后被跳过，攻击也不会丢失。

魔刃正常开放攻击响应并应用合法防具。命中后独立执行判定，结果为白或蓝时尝试使目标冰冻；命中但经铁盾等处理后实际伤害为0，仍执行该命中判定。

## 三、魂刀·英刃

紫爵士使用者下一个自己回合轮到时，在原准备阶段时机打开一次专用可选窗口。该窗口不是准备阶段；静滞随后跳过准备阶段，不影响窗口已经出现。

使用者可选择一名距离4内的在场目标，创建近战伤害4攻击，或主动放弃。超时按放弃处理，不补发。激活与放弃均具备命令权限、窗口修订、优先权、目标重验和命令幂等校验；窗口一旦解决，本次持续期不再出现第二次。

## 四、验证

测试覆盖：魔刃先于目标准备阶段并在0实际伤害时继续判定冰冻；英刃在静滞跳过准备阶段前只开放一次，距离与攻击参数正确；超时放弃且不补发。服务端40个测试文件、181项测试及TypeScript构建全部通过。
