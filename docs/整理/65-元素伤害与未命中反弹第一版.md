# 元素伤害与未命中反弹第一版

## 一、元素防御顺序

1. 每名目标独立建立本次攻击的元素减免额度。
2. 精致法杖与适应进化等数值修正在铁盾前执行。
3. 元素免疫、防具整段防止、铁盾及生命条路由继续按统一伤害段管线执行。

火盾和元素本源免疫火伤害，毒盾免疫毒伤害；装备区失效时这些天赋不生效。伤害事件保存明确的`element`，0实际伤害不触发“首次承受”。

德鲁伊首次在一次攻击中实际承受火或毒伤害后，于该目标的整次攻击处理完成时获得对应永久适应；首次不减免。已有适应时，后续每次攻击对该目标的对应元素总伤减1，而非每段减1；火、毒额度分开，均在铁盾前消耗。

## 二、未命中反弹

- 响应层在攻击上下文中保存明确的未命中原因。
- 道士以出闪、防具闪避或近战格挡等令远程攻击未命中后，在原攻击目标结算完成时登记反弹攻击。
- 刺客仅在以近战武器格挡时登记同类反弹。
- 反弹复制原攻击尚未结算的参数，不复制当前目标临时结果、已有后续队列、已支付的【杀】或出牌窗口；新攻击不支付资源，目标正常响应。
- 反弹复用文档64的嵌套攻击队列；`chainDepth`达到10时，即使第10次再次未命中也不创建第11次。
- 鬼王冠造成的是攻击无效，不作为道士未命中反弹来源。
