# 奉献池配置化随机文案与武器费用闭环

## 已实现范围

- `SP-10`只能在自己的出牌阶段使用，且使用者必须至少有一把已装备武器；常规武器和第三武器均为合法费用。
- 报价公开全部合法费用实例。只有一把合法武器时，命令必须携带明确二次确认；缺少确认时拒绝且状态不变。
- 提交时再次验证出牌窗口、卡牌、武器及确认条件，再原子地将奉献池移入结算区、弃置所选武器、选择文案并将奉献池置入弃牌堆。
- 七条文案来自版本化`settings.special.sp10.flavorLines`，业务执行器不硬编码文字。
- 随机选择使用对局权威随机源并写入随机历史；结果通过领域事件提供给表现层，且明确不产生任何规则效果。
- 武器离场继续经过统一`card.lost`事件后处理桥，可触发血箱等既有规则。

## 冻结包

- 新增`settings.special.sp10.flavorLines`并同步更新`freeze.json`中的`settings.json`摘要。

## 验证

- 覆盖无武器非法、单武器二次确认、配置化可复现随机、多武器无需二次确认及幂等提交。
- 服务端全量回归：62个测试文件、275项测试通过；TypeScript构建通过。
