# SKB v1.3.4武器规则正文

状态：整理期武器正式稿。本文合并五份旧武器来源与WQ01-WQ53，是W-01至W-66的单一规则来源。

## 一、通用规则

- 稳定ID为`weapon.w01`至`weapon.w66`，显示名变化不改变ID。
- 初始牌库共61张：白16、绿15、蓝11、橙7、红12。表中`count=0`的模板不加入初始牌库。
- 多档武器按目标有效距离自动采用能够覆盖目标的最小射程档；射程0只覆盖有效距离0。
- “N目标”表示最多选择N名不同目标，允许少选；每名目标获得一份效果，不因少选叠加。
- 多目标的指定目标后判定、命中判定和濒死按目标分别处理。
- 使用【杀】攻击读取当前预选武器。武器的非攻击主动或濒死效果只要求已装备且有效。
- 多主动方式是预选武器的子状态；手动切换不耗资源。距离档、蓄力档和元素形态自动决定。
- 附加伤害不另开普通响应；基础未命中时，仅明确写“无论命中与否”的附加效果继续。
- 武器攻击具有判定且判中时默认视为暴击；必定暴击可指定成功结果。明确排除时除外。
- 连击/散弹默认整次只响应一次；成功出闪或合法近战格挡抵消全部伤害段。
- 所有合成创建的实例离场后返回牌库外。转变形态离开装备区时恢复原模板。
- 缺少专属图片时使用武器类别占位图，再降级通用占位图。

参数记法：`射程:伤害×段数`。未写段数即1段；“附加”不独立响应；场地默认不可闪、不可近战格挡、无视防具。

### W-56 阿努比斯的权杖

散弹增加令弹头由2发变3发。每发0伤弹头独立指定和响应；命中仍成立但不算造成伤害。全部弹头完成后，对每名目标按命中数判断：

- 3发：必定获得诅咒；
- 2发：判定白/绿/橙/红成功；
- 1发：判定橙/红成功。

诅咒立即生效，到目标下个准备阶段开始前结束：非锁定技失效，不能使用装备区武器攻击；临时获得并自动使用一把牌库外破旧手枪。临时手枪不进入装备槽，诅咒结束后消失。

### W-61 扳手

基础耐久上限和当前值均为2。获得散弹增加时上限和当前值+1；失去时上限-1，当前值超过新上限则压低。拆牌模式在命中后选择，整次攻击不造成伤害；耐久降至0时武器进入其默认离场区。

### W-64 激光鱼

- 第一次支付：自己的出牌阶段指定目标，打出【杀】并消耗1次可攻击次数，只建立瞄准，不发起攻击。
- 若支付后仍有剩余攻击次数，剩余次数立即全部转化为激光鱼攻击。
- 以后每个自己的出牌阶段开始时，锁定消耗全部可攻击次数x，对瞄准目标依次发起x次攻击；阶段内新获得次数也立即消耗并追加攻击。
- 目标超距时对应次数仍消耗但不发起攻击，瞄准保留。
- 出牌阶段可消耗一张【杀】取消瞄准。目标淘汰或离场时自动解除。

### W-66 进水的箱子

目标可以是使用者自己。临时金币不进入手牌，目标立即选择撒币枪或其他合法金币用途并自动打出；没有合法用途、主动放弃或选择超时时金币消失。
