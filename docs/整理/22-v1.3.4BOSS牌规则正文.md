# SKB v1.3.4 BOSS牌规则正文

状态：整理期BOSS牌正式稿。本文合并9种BOSS牌原文及BQ01-BQ50，是v1.3.4 BOSS牌的单一规则来源。

### 使用与BOSS槽

- 每名玩家在每个回合最多使用1张BOSS牌。回合外使用也占使用者在当前回合的额度，但不占其下个自己回合的额度。
- 每人有1个BOSS槽。持续型BOSS使用后进入该槽；即时型不占槽，结算后进入弃牌堆。
- 槽内已有不可替换BOSS时，不能使用另一张需要占槽的BOSS；即时分支不受槽占用影响。
- 除钢铁破浪者号外，BOSS不可主动替换或主动丢弃。钢铁破浪者号可在自己的出牌阶段主动丢弃或被新持续型BOSS替换。
- `rules.boss.allowGenericDismantle`控制泛称拆除公开牌能否选择BOSS槽；v1.3.4默认`true`。限定装备、武器等类别的拆除仍不能越过类别限制。
- BOSS槽不属于装备区，装备区失效不影响BOSS牌。

### 离场、攻击与特殊窗口

- 持续BOSS自然到期、被拆除、被合法替换或持有者淘汰时进入弃牌堆，未创建的效果与专属标记结束；已进入结算的攻击、伤害和触发继续完成。
- BOSS创建的攻击默认不支付【杀】且不消耗可攻击次数；牌面明确费用时除外。它仍是攻击，正常适用响应、无效、减免、命中及濒死规则。
- 静滞角色轮到自己时，仅在原准备阶段时机获得BOSS正文明确允许的特殊窗口。该窗口不是阶段，不触发阶段效果，也不能进行无关操作。
- BOSS的控制免疫阻止外部冰冻、电击及其他限制行动效果，不抵消本牌自身赋予的静滞或阶段替换。
- 有利或可选操作超时默认不发动；强制或不利选择超时由系统随机合法执行。正文另有超时规则时优先。

## 二、B-01 紫爵士

第N回合使用后进入BOSS槽；第N回合结束阶段开始时生效，到第N+1回合结束阶段开始时结束。期间获得铁盾1、静滞、装备区失效和控制免疫。

- **魂刀·英刃**：第N+1回合轮到时，在特殊窗口可发动一次，也可放弃；距离4，近战伤害4。正常允许出闪和合法防具响应，不支付杀或攻击次数。超时不发动且不补发。
- **魂刀·魔刃**：锁定技。持续期内，除使用者外每名在场角色准备阶段开始前，分别对其发动距离不限的近战伤害2攻击；即使其准备阶段将被跳过也先触发。命中后判定，白/蓝使目标冰冻。命中但0伤仍进行判定。

## 三、B-02 红爵士

第N回合使用后进入BOSS槽；第N回合结束阶段开始时生效，到第N+2回合结束阶段开始时结束。期间获得铁盾1、静滞、装备区失效和控制免疫。

每个伤害段先经过无效、免疫、箱子、普通减免及铁盾；结果仍为正数时改为1并实际扣除，计数+1。第四次实际扣除后立即结束BOSS效果，再对自己施加冰冻和电击；随后继续当前伤害段的后置事件及濒死。自然到期不施加冰冻、电击。

第N+1、N+2回合轮到时，各可在特殊窗口发动一次**封灵战锤**：

- 近战段：选择至多1名合法目标，近战伤害3；
- 激光段：选择至多1名另一合法目标，激光伤害3，不可近战格挡；
- 两段均可不选；只选一段只产生该段。两目标属于同一次多目标复合攻击，各自独立响应，均可出闪。超时不发动。

## 四、B-03 钢铁破浪者号

使用后进入BOSS槽，永久生效。角色死亡流程完成后不淘汰，立即解除濒死并移除血量、护盾条；保留座位、回合、手牌、装备及锁定技，非锁定技失效。

- 死亡未淘汰期间仍是未淘汰且未离场的在场角色，可成为目标并占距离，也不触发己方全灭。
- 其不能实际扣除伤害、回复或修改血量/护盾，也不能支付血盾费用；攻击和伤害仍可命中/作用并产生“收到伤害事件”，因此命中后判定、冰冻等仍可触发。
- 因没有实际伤害或实际血量扣除，攻击者的吸血及按实际伤害获益不触发。
- 死亡后的第1、2个后续自己的回合正常进行；第2个回合结束阶段开始时淘汰。死亡发生时的当前回合不计入。
- 死亡后失去本牌会立即淘汰。因此主动丢弃或主动替换为非法操作；外部拆除仍可执行并立即淘汰。死亡前可正常主动丢弃或替换。

## 五、B-04 水晶巨蟹

第N回合使用后进入BOSS槽；从第N回合结束至第N+2回合结束持续生效。期间获得铁盾1、静滞和装备区失效。

第N+1、N+2回合轮到时跳过回合并回复1血。每个“上一自己回合结束后至再次轮到自己”的回合外窗口：

- 每当因一次攻击实际受到正数伤害，在整次攻击及由此造成的自身濒死流程完成后，若仍未淘汰，对该攻击来源发动一次**晶蟹钳子**；
- 同一次攻击无论多少伤害段最多反击一次，不同攻击可分别反击，次数不限；
- 没有合法来源或来源已淘汰而未发起，不计为已反击；
- 若整个窗口一次被动晶蟹钳子都未实际发起，轮到自己时可主动选择目标发动一次；可放弃，超时不发动。

晶蟹钳子为近战伤害1攻击；命中后判定，白/蓝使目标冰冻。

## 六、B-05 C6H8O6

使用时先选择分支并检查全部合法性，再消耗1次可攻击次数。两分支均为特殊出牌请求或直接伤害，不要求目标以闪响应攻击。

### 激光扫射

即时生效，不占BOSS槽。指定【杀】或【闪】，使用者外所有在场角色逆时针各获得一次“以任何方式打出1张指定牌”的机会；手牌及明确视为打出的技能/装备均合法，弃置不算打出。

先收集全部结果，再逆时针对未打出者造成直接激光普通伤害：未打出3/2/1人时每人分别受2/3/5；0人时不创建伤害。每人只响应一次。

### 定点轰击

距离1，选择一名在场角色并指定【杀】或【闪】，本牌进入BOSS槽。要求槽原本为空，或其中是可在死亡前合法替换的钢铁破浪者号。

目标下一个出牌阶段刚结束后触发；该阶段被跳过时也在相应结束检查点触发。连续进行两次指定牌特殊出牌请求：

- 打出0张：受到5点场地伤害；
- 打出1张：受到2点场地伤害；
- 打出2张：不受伤害。

目标触发前淘汰或离场时，本牌弃置且不造成伤害；目标仅死亡但因钢铁破浪者号未淘汰时仍正常触发。结算后本牌进入弃牌堆。

## 七、B-06 暗黑大骑士

第N回合使用后进入BOSS槽；第N回合结束阶段开始时生效，到第N+2回合结束阶段开始时结束。期间铁盾-1、装备区失效、非锁定技失效、可攻击次数为0，且自身一切回复血盾失效，包括濒死救援。

角色仍可使用合法手牌、普通闪等响应及未被关闭的规则操作；一般武器攻击因次数为0不能发动。

- **黑剑**：自己的每个出牌阶段至多发动2次；先当前血量-1，再血量上限-1，立即检查濒死，然后获得1个黑剑标记。黑剑上限2；已满时不能发动且不扣值。黑剑不是牌，不能获取、弃置或拆除。
- **刺击**：消耗1黑剑；距离4，远程/散弹，伤害`2×2`，破除防具、不可近战格挡；可出闪。
- **斩击**：消耗1黑剑；距离2，近战伤害4，破除防具。
- **锤击**：消耗1黑剑；距离2，场地伤害2；命中后使目标电击。
- **最后一击**：持续期内死亡时暂不淘汰。每消耗1把剩余黑剑，可选择一名在场合法目标，依次发动距离不限、近战伤害3、不可近战格挡、破除防具的攻击。每次完整结算及处理目标濒死后才开始下一次。可放弃；选择超时视为放弃全部剩余攻击。无剑或停止发动且相关濒死全部完成后，使用者淘汰。

本牌提前离场时剩余黑剑清空；未发起的最后一击取消并完成淘汰，已发起的攻击继续。

## 八、B-07 大史莱姆

使用后立即进入BOSS槽并获得5点不可回复的临时血量，到第N+2回合结束阶段开始时结束。

- 普通、血量及真实伤害依次经过箱子、铁盾后，优先扣临时血量；护盾伤害直接作用护盾，修改血盾绕过临时血量。
- 一段伤害耗尽临时血量时，该段不溢出护盾或血量。该段结束后本牌立即离场，再由原使用者对自己直接造成5点场地普通伤害并处理濒死，然后继续原攻击的后续伤害段。
- 临时血量不是角色血量，不计入吸血或实际血量伤害收益。
- 自然到期、被拆除或合法离场时，剩余临时血量消失，不造成反噬。

## 九、B-08 金面猴王

使用后进入BOSS槽；第N+1、N+2两个自己的回合生效，到第N+2回合结束阶段开始时结束。每个实际存在的摸牌阶段和出牌阶段分别替换为一次混乱打击，原阶段不发生；被其他效果跳过的阶段不触发替换。

混乱打击先进行颜色判定。白色不发动攻击；其他颜色确定模板后，玩家可发动并选择射程内合法目标，也可放弃，超时视为放弃。此颜色判定不是暴击判定，攻击不耗杀或次数：

- 绿·大菠萝：距离3，远程/连击，伤害`1×3`；
- 蓝·石蟹：距离2，近战/连击，伤害`1×3`；
- 橙·炸药包：距离1，场地伤害2；命中后判定，红/橙追加火伤`1×1`；
- 红·空中支援：距离4，场地伤害2；命中后使目标电击。

炸药包的追加判定按命中触发，即使场地伤害降为0也进行。追加判定不是暴击判定。混乱打击不属于武器攻击，不受武器专属连击/散弹增加影响。

## 十、B-09 瓦尔基里

当他人使用一张非瓦尔基里BOSS牌、已经合法支付费用且尚未开始结算时，可响应使用。将该牌的临时复制实例加入自己手牌，然后原牌继续结算。

- 不能响应自己的BOSS牌；自己当前回合已使用其他BOSS后也不能再使用瓦尔基里。
- 同一原BOSS可被多名其他玩家分别响应，按响应权及后进先出处理；瓦尔基里不能复制瓦尔基里。
- 复制品仅复制模板，不复制已支付费用、选择、目标、持续进度或标记；以后使用时重新支付费用并选择。
- 复制品是可正常使用、获取或失去的真实手牌；复制钢铁破浪者号时保留其全部规则。
- 复制实例从任何区域离场后返回牌库外，不进入普通弃牌堆或重洗。

9张BOSS均使用稳定资源键；加载失败时依次使用BOSS类别占位图、通用占位图。数量、伤害、距离、判定颜色、阶段节点、次数、开关及超时策略全部由版本化配置提供，不按中文显示名或卡牌分支硬编码。
