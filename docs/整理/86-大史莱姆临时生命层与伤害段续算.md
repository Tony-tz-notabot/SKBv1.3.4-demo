# 大史莱姆临时生命层与伤害段续算实现说明

状态：服务端阶段实现记录。B034—B037主流程已实现。

## 一、配置化生命层

大史莱姆成功使用后立即读取冻结BOSS DSL的`specialLayer`定义，在牌实例上创建`giantSlime.temporaryHp`，初始值5且不可回复。自然到期、拆除或其他合法离场会清除剩余层数，不产生反噬。

普通伤害、血量伤害和真实伤害在箱子、免疫、减免与铁盾后先路由至该层；护盾伤害绕过。临时血量计入本段实际伤害但不计为实际血量损失，因此不触发吸血等按实际血量扣除计算的收益。

## 二、耗尽与反噬

耗尽临时血量的当前伤害段截断溢出，先完整产生该段的伤害事实和后置事件，再使大史莱姆离槽。随后以持有者本人为来源，对本人结算5点直接场地普通伤害；该伤害绕过防具与响应，但仍经过无敌、铁盾及普通血盾路由。

## 三、伤害段挂起与恢复

标准攻击把每个伤害段的每次重复展开为稳定的待结算序列，并保存已完成结果及整次攻击元素减免预算。若大史莱姆反噬造成濒死，攻击状态进入`awaitingSegmentDying`，当前目标及剩余具体伤害次数保持不变。

救回后恢复为`targetHit`并从下一次伤害继续，不重新响应、不重新生成攻击元素修正。若目标死亡并淘汰，则丢弃该目标剩余伤害次数，再继续下一个目标或结束攻击。这样满足“先反噬并完成濒死，再继续原攻击后续伤害段”。

## 四、验证

测试覆盖配置化5点临时血、超额单段不溢出、5点自身场地反噬、护盾伤害绕过，以及反噬濒死时剩余多段挂起和救回续算。服务端45个测试文件、201项测试及TypeScript构建全部通过。
