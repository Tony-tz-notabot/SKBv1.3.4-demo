# 水晶巨蟹主动钳子与回合外窗口实现说明

状态：服务端实现记录。对应B020—B023及冻结BOSS正文。

## 一、窗口计数边界

既有被动钳子只在整次攻击造成实际正数伤害、原攻击及自身濒死流程完成、来源仍合法时启动；实际启动后才增加`crystalCrab.passivePincerLaunchedInWindow`。同一次攻击最多排入一次，不同攻击不限次数。

水晶巨蟹第1、2个后续自己回合轮到时，在原准备时机检查上一整个回合外窗口。计数大于0时不开放主动机会；计数为0时开放一次可选主动钳子窗口。检查完成后清除计数，开始记录下一个回合外窗口。

## 二、主动晶蟹钳子

主动窗口可选择任意一名合法在场目标，也可放弃；超时不发动且不补发。攻击为不支付【杀】或攻击次数的距离不限近战伤害1，正常进入响应、命中、伤害和濒死管线。

主动与被动钳子使用同一命中判定参数：命中后判定，白或蓝使目标冰冻。主动钳子不记作上一回合外窗口的被动启动次数。

窗口在回复1血与静滞回合跳过之前创建；回复仍按既有BOSS回合替换执行。命令具备权限、修订、报价、目标重验与幂等校验。

## 三、验证

测试覆盖无被动反击时开放并攻击、主动攻击参数与判定、存在任意次数被动反击时抑制、窗口计数重置、回复节点及超时放弃。服务端42个测试文件、189项测试及TypeScript构建全部通过。
