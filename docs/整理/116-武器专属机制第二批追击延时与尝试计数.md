# 武器专属机制第二批：追击、延时与尝试计数

状态：2026-08-02 完成。

## 已完成

- W07粒子之鹰：初始攻击未命中且存在合法目标时，攻击收尾前向原攻击者开放一次可放弃目标窗口。目标须不是原目标、在原武器射程内且与原目标有效距离不超过1；追击不支付杀或次数，带防递归标签，不能再次产生追击。超时按放弃处理。
- W18天堂之拳：仅蓄力2攻击正式提交后，从冻结`onAttackCommit`创建一次延时快照；在使用者下个准备阶段开始时重验原目标仍存活、在场且未超距，合法则发起同模式`3×2`攻击，不支付杀或次数且不会再次预约，非法则取消。
- W62地下水、W63肉：从冻结`turnAttemptCounter`与动态费用表达式读取规则。自己当前回合第一次支付攻击费用时计数并消耗攻击次数；第二次及以后仍需杀但攻击次数费用为0。杀随后被无效也保留本次尝试计数；进入新的自己回合按回合键自然重置。

## 服务端边界

W07追击使用修订绑定、幂等的独立命令会话，并复用完整攻击响应与伤害管线。W18延时效果保存攻击模式快照，不依赖武器届时仍在装备区。W62/W63共用数据驱动的动态攻击次数解析和实例公开计数器。

## 验证

行为测试覆盖W07合法目标和防递归标签、W18预约与准备阶段启动、W62/W63第二次费用豁免和跨自己回合重置。
