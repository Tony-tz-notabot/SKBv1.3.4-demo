# 开局协议与Vue重摸入口

## 一、正式协议

客户端协议新增`SetupSnapshot`、`SetupCardView`和`SetupSeatState`，根消息类型加入`SETUP_SNAPSHOT`。快照明确包含观看者身份、首个行动座位、牌堆数量、公开弃牌、四座手牌数/重摸完成状态、本人私有手牌及服务器`InteractionView`。

重摸继续使用统一`EXECUTE_OFFER`命令，不新增绕过报价系统的专用客户端命令。报价类型为`resolveChoice`，选择键为`confirm`，布尔值表示是否弃置全部并重摸。

跨字段校验额外禁止：观战者收到私有手牌或报价、私有手牌使用非`private:`引用、公开弃牌使用非`public:`引用、四个座位不完整或重复。

## 二、Vue入口

投影Store现可保存`SetupSnapshot`并将界面切换到`setup`。`SetupRedrawView`展示服务器提供的四张卡牌图片、名称、类别和颜色，并提供“保留手牌”“弃置全部并重摸4张”两个入口；页面只提交当前`offerId + confirm`，不自行移动卡牌。
