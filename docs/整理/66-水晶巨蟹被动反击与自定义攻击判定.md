# 水晶巨蟹被动反击与自定义攻击判定

## 一、被动钳子触发

水晶巨蟹牌处于BOSS槽且已进入生效期时，服务器按每次攻击、每名目标汇总实际伤害：

- 仅在持有者的回合外，且本次攻击对其造成正数实际伤害时登记一次；多段不重复登记，0伤不登记。
- 登记后等待原攻击及该持有者的濒死流程完成。
- 实际启动前重新检查水晶巨蟹持有者和原攻击来源均未淘汰且仍在场；不合法则跳过，且不增加“本窗口已实际被动反击次数”。
- 合法时启动距离不限、近战1、无需【杀】和攻击次数的标准攻击，并将本窗口实际启动次数加1。

## 二、自定义攻击判定

攻击上下文现可携带`customJudgments`，与武器模板判定共用真实判定牌、判定前干预、判定结果、附加效果和暴击管线。晶蟹钳子命中后判定白或蓝成功：成功使本攻击暴击，并向目标施加/刷新冰冻；失败只造成基础伤害。

## 三、尚待同一BOSS生命周期阶段完成

水晶巨蟹的使用、两回合持续期、静滞/装备区失效、跳过回合回血、窗口重置及“整窗口未实际反击时可主动钳子”需要BOSS牌主动使用与持续期执行器，后续统一接入；本阶段不以测试夹具中的`runtime.active`代替该生命周期。
