# 通用动作、费用、目标与报价第一版实现说明

本阶段在第59号基础闭环之后，按最终规则与DSL实现了通用主动动作的首个服务器执行切片。

## 已实现

- 角色与卡牌目标规范：数量、去重、敌友、自他、在场/未淘汰、生命状态、区域、公开性、模板及距离过滤。
- 距离计算：淘汰者不占位；超界者离场仍占位；进攻与防御距离修正带符号相加，最终最低0。
- 费用计划：手牌卡牌、血量/护盾/铁盾数值及次数额度；同一实体牌不能重复支付。
- 动作执行固定经过声明、合法性、目标、费用、提交和解析事件；提交前重新验证目标与费用，解析异常整体回滚。
- 动作报价只投影当前合法目标与费用候选，并标识整体是否可支付。
- 动作命令会话校验修订、提示、操作者、报价和选择；命令幂等，成功后保留出牌窗口并按新状态重新报价。
- 修复旧状态不变量：只有`deadNotEliminated`允许`hp/shield=null`，其他未淘汰生命状态仍必须有血盾数值。

## 当前边界

本版建立的是通用骨架，还未把冻结分类规则包逐项编译为动作定义，也未实现攻击、响应和伤害执行器。下一步先实现武器预选解析、攻击提案与标准攻击费用/目标提交边界，再接响应窗口和伤害段。

## 验证

服务端现有17个测试文件、51项测试及TypeScript构建通过。
