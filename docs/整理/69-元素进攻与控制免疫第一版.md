# 元素进攻与控制免疫第一版

状态：服务端第一版实现完成；攻击外直接伤害执行器待后续通用效果阶段消费。

## 已实现

- 火盾、毒盾按每名目标、每次攻击各使第一个合法对应元素段的 `repeat +1`，包含附加元素段，明确标记 `ignoresTalent` 的攻击或伤害段除外。
- 电盾不再提供感电总伤 +1；元爆仍令火、毒、感电对应总伤各 +1（感电伤害保留）。总伤加值只放入第一个正数对应元素段的第一次重复，不会错误地给全部重复段逐段加值。
- 初始天赋不随普通装备区失效关闭；装备在天赋区的同名天赋仅在装备效果有效时生效。
- 冰盾、元素本源免疫冰冻；电盾免疫电击。状态免疫统一在 `applyStatusInTransaction` 入口执行。
- 冰盾只有在冰冻实际应用或刷新后才追加毒1；被免疫时不追加。攻击内直接追加为统一伤害段，攻击外登记 `immediate.damagePipeline` 效果，待通用直接伤害执行器消费。
