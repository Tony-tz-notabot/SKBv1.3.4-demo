# SKB v1.3.4非BOSS牌DSL目录与追踪说明

状态：完成。128种模板、267张物理牌的效果DSL及P001-P052追踪全部完成，待编码模板为0。

## 一、数量口径

`rulesets/v1.3.4/nonboss-rules.json`区分模板数与物理牌数：

| 类别 | 模板数 | 初始牌数 |
| --- | ---: | ---: |
| 基础牌 | 22 | 132 |
| 防具 | 9 | 8 |
| 天赋 | 25 | 50 |
| 坐骑 | 11 | 11 |
| 雕像 | 50 | 50 |
| 特殊牌 | 11 | 16 |
| 合计 | 128 | 267 |

五色同名牌保留各自`cardId`和印刷颜色，但引用共享效果族。雕像仍是10个效果族、50个颜色模板。

## 二、基础效果族

| 效果族 | 模板数 | 编码要点 |
| --- | ---: | --- |
| `basic.kill` | 5 | 绑定攻击费用和印刷颜色；读取预选有效武器或合法手刀，不作为独立伤害牌执行 |
| `basic.dodge` | 5 | 只在合法攻击响应窗使用，令整次攻击全部段失效并视为未命中 |
| `basic.potion` | 5 | 自己出牌阶段回复自己2血；任意濒死救援窗为当前濒死者回复2血 |
| `basic.horn` | 5 | 出牌阶段自疗1或建立本回合下次武器攻击必暴持续实例；濒死时仅能自救1血 |
| `basic.coin` | 2 | 普通实例可进手牌；临时实例不进手牌，必须立即选择合法用途，放弃/超时后返回牌库外 |

强力药水对药水和号角的回复量统一通过有效天赋查询增加1，未在基础牌效果中按角色或中文名硬编码。

## 三、防具效果族

A-01至A-09均使用稳定牌ID作为效果族ID，已经明确：

- 判定防具每次攻击仅尝试一次，失败不关闭后续合法响应；
- `ignoreArmor`统一关闭防具触发和防具来源的攻击无效；
- 箱子按伤害段强制防止并消耗耐久，优先于钢铁护盾，耐久归零后完成当前段再离场；
- 盾牌、圆盾在攻击提交前令对应印刷颜色的【杀】无效，费用和攻击次数不退、蓄力不变；
- 精致法杖按命中的整次远程攻击消耗每轮额度，仅修改其第一个正伤害段；全为0伤仍消耗额度；
- 斩首者出手牌【杀】进行近战格挡，令整次远程攻击未命中，并产生近战格挡响应事件；
- 陷阱箱按耐久消耗顺序把反击排到原攻击后，最后一次反击完成后才移除合成实例。

## 四、天赋效果族

25种天赋均使用稳定`talentId`作为效果族ID，已经明确：

- 同名天赋检查同时包含普通天赋与初始天赋；非法装备执行“失去手牌并摸1”，不产生装备或弃置事件；
- 三持失去时只检查常规武器槽，超槽选择为强制操作，超时随机；上限类天赋离场仅把当前值压到新上限；
- 毒盾、火盾按每目标每攻击增加对应元素段数；电盾把总伤增量放入首个正数感电段；
- 吸血、吸蓝只累计实际血量扣除，按每目标每攻击至多触发一次，攻击死亡未淘汰角色不会产生收益；
- 蓝盾、刺盾均按独立伤害段处理；前者读取段开始时护盾，后者只修改近战攻击首个正数段；
- 精确打击按目标独立判定，红/橙判中同时应用暴击与“禁普通手牌闪”，不关闭技能闪、防具和近战格挡；
- 暴击穿透锁定原武器和原方式，另付【杀】但不耗攻击次数，并用标签禁止递归；
- 雕像双触的返回计划独立于雕像效果是否被无效；额外宝石在本次濒死结果确定后按获救/死亡分支移除。

## 五、坐骑效果族

M-01至M-11均已编码：

- `+`、`-`与`±`分别占防御槽、进攻槽或同时占两槽；数值为0不取消槽位占用；
- 装备新坐骑时替换所有与所需槽冲突的实例；`±`坐骑始终作为一张牌整体离场并释放两槽；
- 坐骑只参与声明需要距离检查的操作，距离不限不读取坐骑修正，最终有效距离最低为0；
- 百变怪在`distance.calculate`实时查询有效火/毒/冰/电盾，包含初始天赋，排除失效的普通天赋；百变怪自身失效时关闭全部修正。

## 六、雕像效果族

10个共享效果族已经绑定白、绿、蓝、橙、红共50个模板：

- 普通雕像限定自己出牌阶段，圣骑士雕像独立使用效果响应窗并按后进先出处理；
- 狼人雕像分别建立直接护盾/血量伤害，以实际扣除值恢复，0伤不恢复；
- 精灵/盗贼统一使用“公开牌正面＋服务端随机排列的手牌背面”候选视图，排除初始天赋；
- 牧师雕像按在场人数展示，从使用者逆时针每名未淘汰角色仅获一次可放弃选择，超时放弃，余牌弃置；
- 骑士雕像的决斗从目标开始交替出【杀】，胜者可放弃攻击；蓄力武器复制蓄力0临时实例，不修改原装备；
- 刺客雕像按逆时针逐目标完整结算距离不限远程飞镖攻击；
- 工程师雕像保存最初来源，在判定区末尾循环移动，来源淘汰不取消，绿色分支造成血量伤害并移除。

## 七、特殊牌效果族

SP-01至SP-11全部完成：

- 网瘾系列使用特殊出牌请求，不创建攻击；先收集全部响应，再逆时针逐人造成伤害并即时处理濒死；
- 羊叫兽阶段一设置结算屏障，所有响应、伤害和禁闪完成后才嵌套执行完整网瘾少年；合成材料进入弃牌堆，产物离场返回牌库外；
- 死亡笔记和鲜血祭坛使用数值修改操作，不误入普通伤害、无敌或铁盾流程；
- 重铸熔炉先弃费用武器再最多展示8张，牌堆耗尽可重洗并重新出现费用牌；起源熔炉按费用武器印刷颜色读取摸牌配置；
- 号角小队只把“实际出【杀】的一般武器攻击”的次数费用改为0，不增加次数，也不影响显式耗次数的能力；
- 拆迁大队先逐人可选弃置，再从快照同时传递包括第三武器的全部剩余武器，最后按实时槽位强制处理溢出；
- 超级大宝贝儿只有仍在判定区时触发，先处理全员特殊出闪与血伤，再处理使用者外在场角色的火、毒段；
- 鲜血诅咒监听合法目标与【杀】支付完成后、杀无效检查前，每个自己的回合限首次触发。
