# 元素锦囊与矿工遁地时间线第一版

## 已闭环

- R024元素锦囊提供修订绑定、幂等主动报价。冰冻、雷电、烈焰三个选项各整局一次，并共享每个自己出牌阶段一次限制。
- 烈焰锦囊按目标提交时的合法牌重算：0张时不报价，1张必须拆1张，至少2张必须拆2张；选择错误或牌已失效时不消耗选项。
- 矿工在自己出牌阶段正文结束、`phase.after`之前获得一次可放弃窗口；发动必须弃1张手牌，随后获得遁地及其独立铁盾1。
- 遁地使已经合法支付的远程攻击直接未命中；0伤不退出，实际正数伤害立即退出。
- R026自然退出发生在矿工下个准备阶段的正常回盾之前：先移除遁地及其铁盾贡献，再强制选择在场目标，排入1点场地直接伤害；超时权威随机。

## 仍在迁移

R025尚未宣告完整闭环。普通闪、技能闪、近战格挡等标准攻击主动响应已经接入“退出遁地并选择拆来源牌”；仍需逐一迁移判定防具响应、濒死救援牌以及非攻击特殊牌响应等所有回合外主动出牌生产点。无关的回合外主动出牌只退出、不拆来源，必须在统一出牌事件入口完成覆盖后才可关闭R025。

当前全量验证：服务端76个测试文件、324项测试通过，TypeScript生产构建通过。
