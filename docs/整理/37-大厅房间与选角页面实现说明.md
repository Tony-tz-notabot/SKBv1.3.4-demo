# 大厅、房间与选角页面实现说明

状态：首批只读页面已完成并通过浏览器验收。

## 一、已实现页面

- `LobbyView.vue`：账号摘要、创建/加入入口、可恢复对局、图鉴和设置入口；
- `RoomView.vue`：房间摘要、四座环形场面、准备/连接状态、房主标记和规则设置；
- `CharacterSelectionView.vue`：当前观看者的四个私密候选、基础血盾/天赋/技能/难度、预选和锁定状态；
- `SeatCard.vue`：房间和选角共用的座位显示组件；
- `dev/mockServer.ts`：开发期模拟服务器，所有模拟快照仍通过正式协议网关和Ajv验证后进入Store。

## 二、最新座位视角裁定

页面按`viewerSeat`旋转：

- 当前观看者座位在下方；
- 规则逆时针下一座在右侧；
- 对座在上方；
- 上一座在左侧。

旋转只改变显示坐标，真实座位号、A/B队归属、回合方向、距离和结算顺序不变。无座位观战者暂以1号座位视角显示。

浏览器使用2号观看者样本验证结果为：2号下、3号右、4号上、1号左。

## 三、隐私与权威边界

- 选角页只遍历`RoomSnapshot.characterSelection.candidates`，该字段只属于当前观看者私密投影；
- 他人座位只显示`choosing/locked/revealed`状态，不读取候选或锁定角色ID；
- 页面props接受深只读快照，不要求解除Store的只读保护；
- 开发模拟器不能直接写页面状态，必须走协议网关；
- 当前按钮尚未连接命令构造器，因此保持禁用或仅作入口表现。
