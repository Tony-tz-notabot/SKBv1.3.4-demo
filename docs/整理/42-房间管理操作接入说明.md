# 房间管理操作接入说明

## 一、已接入命令

房间等待页现已接入协议已有的全部管理操作：

- `UPDATE_ROOM_SETTINGS`：编辑房间名称、游客、观战、三类计时及泛称拆除 BOSS 设置；
- `CHANGE_SEAT`：玩家选择空座，队伍随固定座位重新确定；
- `KICK_PLAYER`：房主移出其他玩家；
- `TRANSFER_HOST`：房主转让给另一名玩家；
- `START_GAME`：进入私密角色选择阶段；
- `LEAVE_ROOM`：主动离开并返回大厅；
- `CLOSE_ROOM`：关闭房间并返回大厅。

准备与聊天继续使用原有命令。所有房间内命令都由动作服务从最新服务器投影读取 `roomId/expectedRoomRevision`，页面不能自造修订号。

## 二、权限和确认

- 编辑设置、换座、踢人、转让房主、开始及关闭入口由 `RoomPermissions` 分别控制；
- 权限投影只控制当前显示和可点击状态，不替代服务器权威校验；
- 踢人、转让房主、离开和关闭房间有显式确认；
- 换座只展示当前投影中的空座，服务器仍须处理并发抢座；
- 转让后旧房主的权限以服务器下一份快照为准。

## 三、开发模拟

开发模拟服务器已支持上述命令，并继续通过正式协议网关写入投影：设置会回写新快照，换座会更新队伍和观看者座位，踢人会产生空座，转让会更新房主和权限，开始进入选角，离开与关闭返回大厅。
