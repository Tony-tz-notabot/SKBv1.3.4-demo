# 拆迁大队多人武器传递闭环

状态：服务端第一版实现说明。对应 P046 与 `special.sp08`。

## 一、第一阶段：逐人可弃

使用者在自己的出牌阶段打出拆迁大队后，原出牌窗口挂起。系统从当前回合玩家开始按逆时针顺序，依次向每名未淘汰玩家提供一次选择：

- 可以弃置0把或1把自己当前已装备的武器；
- 常规武器和第三武器均为合法选择；
- 提交时重新验证牌仍位于该玩家的武器槽；
- 超时视为不弃置。

每名玩家只处理一次，后续传递和槽位冲突不会重新开放本阶段。

## 二、第二阶段：快照同时传递

所有第一阶段选择完成后，服务器保存各参与玩家“剩余常规武器＋第三武器”的统一快照。随后先把快照内全部武器移出原槽，再按快照传给逆时针下一个未淘汰玩家，从而保证结果不受逐张执行顺序影响。

- 常规武器仍作为常规武器传入；
- 第三武器保持第三武器分类并进入接收者第三武器槽；
- 淘汰玩家不参与选择、快照或接收，前一参与者直接传给逆时针下一参与者；
- 离开原装备槽会产生完整 `card.lost` 来源快照。

## 三、第三阶段：槽位冲突

传递完成后按原参与顺序检查接收者：

- 常规槽上限通常为2；有效三持或初始三持时为3；
- 第三武器槽上限为1；
- 若超额，玩家必须按常规/第三武器各自的超额数量精确选择弃置；
- 不允许用多弃第三武器替代常规槽超额，反之亦然；
- 超时按两个分类分别使用权威可复现随机源选择。

所有冲突处理完后压紧常规武器槽，拆迁大队进入弃牌堆，并恢复最初使用者的出牌窗口。

## 四、验证

- 覆盖四人逐项放弃、主动弃第三武器、淘汰者跳过和接收者跳转。
- 覆盖三持上家传三把常规武器给普通下家、精确弃1、槽位压紧和第三武器分类保持。
- 覆盖命令幂等、超时放弃及可复现随机超额弃置。
