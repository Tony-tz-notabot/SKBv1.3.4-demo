# 65-判定干预萨满专属裁定

状态：正式裁定。规则作者确认。

## 背景

判定干预窗口（`judgmentIntervention`，翻牌后替换判定牌）与萨满“逆天改命”窗口（`preJudgment`，翻牌前指定结果）原实现为四人逆时针轮转。作者裁定两者均改为萨满专属，判定替换另加成本与限次。

## 裁定

1. **判定干预窗口萨满专属**：当且仅当有在场萨满时出现，仅萨满可见可操作；无萨满在场时判定直接结算，不出现窗口。
2. **替换成本**：萨满替换判定牌需弃置 2 张同色手牌。
3. **替换限次**：每个判定限 1 次替换；替换后重开窗口，此时只剩放弃选项。
4. **逆天改命窗口萨满专属**：仅萨满可发动，支付 2 张同色手牌并指定五色之一，不产生真实判定牌；无萨满时直接进入普通判定。
5. **无萨满路径不得留下无窗口判定帧**：判定必须在同一事务内自动结算完成，避免调度器死锁。

## 实施要点

- `judgment.ts` 抽出 `finalizeJudgmentInTransaction`；无萨满时在 `beginJudgmentInTransaction` 内联自动结算并续接三个分支。
- `openInterventionWindow` 固定 `prioritySeat = shamanSeat`，`legalOfferIds` 仅含放弃与替换（替换需 `replaced !== true`）。
- `replaceJudgmentCardInTransaction` 校验 2 张同色手牌并弃置，旧判定牌入弃牌堆，翻真实新牌，`context.replaced = true` 后重开只剩放弃的窗口。
- `preJudgment` 固定 `prioritySeat = shamanSeat`，pass 一次即关窗进入 `beginJudgment`，移除四人轮转。
- 引擎与测试已同步：`server npm test` 全量 115 文件 / 501 用例通过。
