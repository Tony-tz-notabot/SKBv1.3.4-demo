# 开局手牌与重摸正式裁定

状态：已由规则作者确认，应并入v1.3.4开局流程。

## 正式规则

1. 建立牌堆并洗牌后，每名玩家从牌堆顶获得4张初始手牌。
2. 正式开局前，每名玩家各有一次可选的重摸机会。
3. 选择重摸时，将自己的全部4张初始手牌弃置，再从牌堆顶获得4张牌；不能只重摸其中一部分。
4. 被弃置的原初始手牌进入弃牌堆，不放回牌堆，也不因重摸主动触发洗牌。若取牌过程中牌堆耗尽，仍按通用牌堆耗尽规则处理。
5. 放弃或完成重摸后，该玩家本局不再拥有开局重摸机会。所有玩家完成选择或超时后，才进入正式对局时间轴。
6. 重摸属于对玩家有利的可选操作，超时默认不重摸。

上述数量和超时策略必须从规则集设置读取，不得硬编码在服务器流程中。
