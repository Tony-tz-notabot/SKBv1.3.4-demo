# SKB 第二轮角色正式裁定

状态：C01-C50 已由规则作者全部裁定，角色第二轮裁定完成。

## 一、全局表述补充

1. “每个回合”默认指技能拥有者/当前叙述主体自己的每个回合；若包含他人，必须写“任意角色的回合”“所有角色的回合”或具体角色。
2. 摸牌修正值可以降至0以下，但实际摸牌最低0张。
3. 选择目标一张牌时，界面同时显示目标所有公开具名牌和经随机排序、不展示正面的统一手牌牌背。发动者可直接选择公开牌，或从牌背中选一张；不得查看手牌正面后选择。
4. 未写距离的角色技能默认距离不限；明确使用武器/手刀时采用对应射程。
5. 不同及重复来源的“下回合摸牌±N”可以叠加；对应阶段结束或被跳过后消除。
6. 技能写“牌”时包含所有合法区域；写“手牌”时只允许手牌。

## 二、骑士至圣骑士

1. 骑士本能：原雕像保留印刷颜色，本次打出时必须明确标出“转换为骑士雕像”；本次名称、身份和效果均按骑士雕像，可被圣骑士雕像响应；结算后恢复原身份。
2. 毒瓶创建距离2、单目标的场地攻击，命中产生毒伤害 `1×2`；不可闪、不可近战格挡、无视防具，但可被非防具攻击无效和无敌处理。
3. 猫头鹰一轮限一次；同一攻击全部伤害段结束后，若枭首者实际受伤，再选择是否对来源发起吹箭攻击。
4. 斯巴达飞踢的减摸牌可以叠加；破盾按本次护盾伤害是否令护盾从大于0变为0判断。
5. 狼人笔记：检查费用和目标→弃置五色手牌各一张→血量上限+1并回复1血→执行死亡笔记。支付完成后不因目标后续失效退还收益。
6. 神圣屏障共用一个 CD=1。伤害窗口发动时免疫该伤害并获得无敌；出牌阶段主动发动时只获得无敌。
7. 神圣屏障可弃置任意合法区域中的两张蓝色牌；装备离场触发失去装备，初始天赋不可选。

## 三、精灵至牧师

1. 专注射击在一名来源对精灵的全部伤害段结束后检查；只要造成血量伤害就瞄准该来源，后发生来源覆盖旧瞄准。
2. 对瞄准目标攻击仍需【杀】和当前预选有效武器，只是不消耗攻击次数；整次攻击造成血量伤害后解除。
3. 游侠翻滚令自己下个回合内所有以【杀】发起的攻击必定暴击；到该回合结束清除，即使出牌阶段被跳过。
4. 道士反弹复制原攻击尚未结算的完整参数，以原攻击者为伤害来源和新目标，不支付资源；被反弹者可以正常响应。
5. 同一攻击链允许连续反弹，最多10次。达到10次后不能继续反弹；若第10次攻击再次被避开，攻击链结束，不创建第11次攻击。
6. 祈祷的回合外与回合内用法共享每轮一次额度，在牧师准备阶段重置。
7. 希望改为“弃置一张白色手牌”，不再允许从装备或判定区支付。

## 四、拳击柱与超界者

1. 惯性反击累计每名来源实际造成的全部伤害，包括额外生命层、护盾和普通血量承受的伤害；不记录0伤、直接修改数值和已结算份额。
2. 来源死亡但未淘汰时照常反击；已淘汰时清除累计值，不再造成伤害。
3. 超界者血量下限只在自己的结束阶段-1，不在其他玩家结束阶段下降。
4. 平行穿梭对每个即将造成的伤害段分别判定；绿/蓝只令该段无效。0伤段不判定。
5. 致命诅咒发动后的下一个超界者回合记第1次；第3次轮到时直接进入结束阶段，在结束阶段开始时处决仍存活的标记目标并恢复超界者，然后处理其他结束阶段效果。

## 五、古代元素使至恶魔术士

1. 烈焰锦囊在目标至少有一张可拆牌时合法，有几张拆几张，最多两张；无可拆牌时选项非法且不消耗次数。
2. 矿工回合外主动出牌必定退出遁地；只有该行为属于响应攻击/伤害时才拆除相应来源一张牌，无来源时只退出。
3. 遁地自然结束发生在矿工下个准备阶段开始时、正常回盾之前：退出、选择目标造成1点场地伤害，再继续准备阶段。
4. 地狱烈火在一次攻击原始伤害段完成后检查；实际造成伤害才判定一次，白/红时对当前目标追加1点火伤害；多目标分别判定。
5. 恶魔本性两个目标逆时针逐个结算，之后才回复2血、增加1护盾上限并处理铁盾奖励。恶魔术士中途被淘汰则取消剩余目标和后续奖励。
6. 被命中目标从其下一准备阶段起连续 `x+1` 次准备阶段不能自动回盾；恶魔术士铁盾持续到其第 `x+1` 个后续准备阶段开始前。

## 六、死灵法师至法师

1. 灵魂打击按实际伤害点数获得能量；3点单段或 `1×3` 均获得3能量，0伤和修改数值不获得，上限8。
2. 同一目标不能叠加死灵标记；再次施加刷新持续期，并把负铁盾额外伤害累计值重置为0。
3. 死灵标记以死灵法师为主体，持续到死灵法师两个回合后的准备阶段开始前；对应回合被跳过仍计数。
4. 能量过载距离不限，对机器人之外所有人逐个发起2点激光攻击；可闪、不可近战格挡、不破防，不受电盾及其他天赋加成。
5. 刺客信条第一种提供防御距离+1，持续到刺客下个准备阶段开始前；第二种在刺客自己的下个回合提供进攻距离-1，持续该回合；两种额度独立并在准备阶段重置。
6. 法术打击每次【杀】攻击命中后最多发动一次；多段攻击只触发一次，暴击穿透产生的新攻击可另行触发；技能伤害不受元爆。

## 七、气宗至工程师

1. 元气蛋蛋每回合出牌阶段限一次；弃置2张手牌，指定距离不限的一名角色，发起元气弹攻击；不消耗【杀】，消耗1次可攻击次数。
2. 元气弹的火盾/毒盾效果分别追加1点附加火/毒伤害，不受暴击；刺盾令基础伤害段+1；碎盾命中后由气宗拆目标一张牌；冰盾命中后判定一次。
3. 电盾令元气弹不能用普通【闪】或技能视为【闪】响应，只允许使用未被攻击标签禁止的防具和近战武器格挡。
4. 吸炸在一次攻击结算后汇总对他人造成的血量伤害，每满2点获得1炸弹；直接伤害和修改血量不触发。
5. 炸弹主动引爆是距离不限的场地攻击，每个炸弹形成1点场地伤害段；无论命中与否，准备阶段结束时全部清空。
6. 炸弹防御在免疫、减伤和铁盾后强制消耗，消耗 `min(炸弹数, 铁盾后伤害值)`，逐点抵消；最终0伤不视为受到伤害。
7. 工程师第一次准备阶段选择机甲并记第1回合，第2、3次准备阶段仍在机甲中，第4次准备阶段开始时退出后再正常处理准备阶段。
8. 普通、护盾和血量伤害优先作用机甲护盾，单段溢出不进入角色本体；修改角色血量/护盾直接作用本体。机甲护盾归零立即退甲，后续伤害段正常作用角色。
9. 进入机甲后对应机甲武器自动成为唯一有效预选；攻击仍需【杀】和攻击次数。机甲武器不是卡牌实例，不能移动。
10. 从开局至退甲前不能装备；退甲后可在同一回合后续出牌阶段装备。
11. 工程师可以在自己的出牌阶段主动退出机甲；退出后本局不能再次进入机甲。

## 八、德鲁伊与将军

1. 适应进化在首次元素伤害完整承受后获得对应永久减免，不减免首次伤害。
2. 元素减免按整次攻击计算；每个已适应元素令该元素总伤害-1。火毒同时具有火、毒，可分别-1、合计最多-2；减免在铁盾之前处理。
3. 汪汪队采用全场触发特例：任意角色的结束阶段都触发，一轮通常4次。每次只对当回合结束的角色（包括将军）发起距离不限的1点近战护盾伤害攻击。（2026-08-13 修订：由"对所有未淘汰角色逆时针逐个"改为"只对当回合结束的角色"。）
4. 迫击炮距离不限，对所有未淘汰且可受效果角色（包括将军）逆时针逐个直接造成3点场地普通伤害；每个目标结算伤害和濒死后再继续下一目标。

## 九、狂战士与萨满

### C47 狂战的宣告与摸牌修正（已裁定）

摸牌阶段开始时、实际摸牌前选择不发动/少摸1/少摸2。先计算应摸N张，再减少所选值，实际摸牌最低0。必定暴击只作用本回合第一次正式发起的武器攻击；杀被圆盾提前无效不消耗；回合结束清除。

### C48 未卜先知与摸牌数（已裁定）

应摸N张时展示N+2张并选择N张，N最低0；未选牌进入弃牌堆；摸牌阶段被跳过时不展示。
