## 0. 设计原则

1. **只做入场/状态反馈，不做离场动画**：离场动画（leave）会延迟 DOM 移除，jsdom 测试在点击关闭后立即断言元素不存在会失败；入场动画（元素挂载时自动播放一次）零结构风险。
2. **挂载动画优先**：v-for 列表（手牌/弃牌/判定区/聊天/报价按钮）的元素以 `card.ref`/`messageId`/`offerId` 为 key，新元素挂载即播放 CSS `animation`，旧元素复用不重播——无需 TransitionGroup、不改父结构。
3. **只用 transform / opacity / filter / box-shadow**，不动 layout 属性，避免重排；一次性动画为主，常驻动画仅"行动玩家呼吸光环"一处。
4. **`prefers-reduced-motion: reduce`** 全局关闭动画与过渡（标准降级写法）。
5. 服务端投影、协议、引擎零改动；Vue 模板改动尽量小，且每处先核对对应测试。

### B. 血盾条设计 v1（作者要求落地）

**几何（CSS 自定义属性，可调）**

| 属性 | 值 | 说明 |
|---|---|---|
| `--bar-h` 条高 | 7px | 细式 |
| `--bar-unit` 单点长 | 14px = 2×条高 | "单点等效长度是高度的2倍" |
| 参考上限 | 12 点 → 168px | 与装备区等宽，看效果再调 |
| 上限 >12 | 单点按比例收缩 `unit = 168/max` | 总长保持 ≤168px，数值照常（如拳击柱 22 上限） |
| 边框 | 无 | 圆角 3px |
| 布局 | HP 一行（红）、SH 一行（灰），行距 3px，**数值在条左端外侧** | |

**填充与失去部分**：填充=主题色实色（HP `#ff857a` / SH `#dde6ec`，**已按作者要求提亮**，上浅下深微渐变 + 同色微光晕）；失去部分=轨道，主题色 12–14% 透明度叠加深色渐变（`rgba(0,0,0,.38)→.2`）——"失去部分深度增加、透明度明显增加"。填充宽度变化 `transition .22s`。
**单点刻度线**（**默认关**、线已调淡）：轨道/填充上叠加 `repeating-linear-gradient` 每 14px 一条 1px 低透明分隔（轨道白线 alpha .04、填充黑线 alpha .10）——预览页可开关，看效果定。
**数值**：`当前/上限`（如 5/12）等宽字体 `ui-monospace/Cascadia/Consolas` + `font-variant-numeric: tabular-nums`，字号 .62rem，防跳动；**位于条左端**。
**加减特效与弹数字**：减少→填充收窄过渡 + 闪红（`bar-flash` brightness 脉冲 400ms）+ 浮动数字 `-N`（红，上浮 30px 淡出 0.9s）；增加→闪绿 + `+N`（绿）。浮动数字定位在对应条上方，等宽字体 + text-shadow；watch 快照差值（跳过首次、连续变化取净差），id + setTimeout 清理。
**主题化备用条**：`.bar--hp/.bar--shield/.bar--purple/.bar--blue`（提亮色：紫 `#c9a3f0`、蓝 `#93d0f0`），props `{value,max,theme,label}`；用于临时多出资源（如死灵法师灵魂——当前 `PlayerView` 尚无该字段，组件先就绪、数据接入待服务端投影提供后完成）。备用条置于 SH 行之下，同款细式。
**牌数/在线迁移**：从 vitals 行移出 → 面板**最右下角微角标**（`right:6px; bottom:2px`，等宽 `.55rem`，opacity .55，`cards 4/12 · online/offline`，online 绿/offline 灰保持原色）。与右侧半透明头像叠放不抢眼；如看效果仍嫌遮挡，备选：装备区下方右侧微型行。
**铁盾等特殊状态图标**（作者 2026-08 第三轮）：**一律放在血盾条下方、装备区上方**——即现有 meta 行位置，扩展为"特殊状态图标行"（铁盾、状态、感电等图标统一在此行，不再放右上角/数值行）。原 vitals 徽章移除后，铁盾由徽章改为该行图标（`铁 N`，.62rem 芯片式）。
**面板布局变化**：原 vitals 徽章行（≈22px）→ 两行细条+数值（≈20px），高度基本持平；角标绝对定位不占高 → **面板高度几乎不变（≈179/194px），对中央区无新增挤压**。
