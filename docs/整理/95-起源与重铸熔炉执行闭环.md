# 起源与重铸熔炉执行闭环

状态：服务端第一版实现说明。对应 P044 及特殊牌 SP-05、SP-06。

## 一、共同边界

- 两张牌均只在使用者自己的出牌阶段提供报价，且必须有至少一把已装备武器。
- 常规武器槽与第三武器槽中的真实武器实例都可作为费用。
- 命令绑定对局、状态修订、当前提示、牌实例和所选武器；提交前重新验证，失败不改变权威状态。
- 特殊牌先进入结算区，费用武器随后以“弃置”离开装备区并产生完整 `card.lost` 快照；牌效果完成后特殊牌进入弃牌堆。

## 二、起源熔炉

按费用武器的印刷颜色从冻结 DSL 读取摸牌数：白/绿2，蓝/橙3，红4。摸牌复用统一真实牌堆管线，可以跨弃牌堆重洗；双堆不足时记录实际少摸。

费用在摸牌前支付，因此牌堆恰好耗尽时，刚弃置的费用武器可以参与重洗并被摸回。正在结算的起源熔炉不进入重洗。

## 三、重铸熔炉

费用支付后从牌堆顶逐张把真实牌移入中央结算区并公开展示，直到：

1. 展示到一把颜色等级不低于费用武器的武器；或
2. 已展示8张；或
3. 牌堆和可重洗弃牌堆均耗尽。

颜色等级由 `settings.cardColorRank` 版本配置提供，当前为白＜绿＜蓝＜橙＜红，业务代码不硬编码等级。

只要展示牌中存在武器，就打开强制选择窗口；可以选择任意一把已展示武器，不要求其达到停止等级。所选武器进入使用者手牌，其余展示牌进入弃牌堆。若没有展示出武器，则没有选择窗口，全部展示牌直接弃置。强制选择超时使用权威可复现随机源。

费用武器在展示前进入弃牌堆，故展示过程中牌堆耗尽并重洗时，它可以被重新展示并最终选回；正在结算的重铸熔炉和已经展示的牌均不参与重洗。

## 四、验证

- 覆盖起源熔炉五色摸牌数、第三武器费用、跨重洗和实际少摸。
- 覆盖重铸熔炉等级停止、8张上限、任意展示武器可选、无武器自动结束、费用武器被重洗展示、选择幂等及随机超时。
- 服务端59个测试文件、262项测试全部通过；TypeScript生产构建通过。
