# SKB 规则整理索引

本文档集把现有散落资料整理为可继续修订、数据化和实现的工作底稿。原始文档保留为历史来源，不直接覆盖。

## 一、当前结论

- 当前正式玩法基线是《Soul_Knight_Battle》通用规则 v1.3.3。
- `skb 规则补丁1.3.1.1.md` 正文实际标为v1.3.4；其中蓄力、连击/散弹、合成、第三武器已经作者确认并正式并入正在整理的v1.3.4。
- `skb 规则补丁1.3.3.2.md` 中的静滞、装备区失效视为 v1.3.3 的有效增补。
- `skb 1.3.3 注意点.md` 是对现行文本的澄清；与更早的 `skb 1.3.2注意点.md` 重复时采用 1.3.3。
- 各角色和卡牌专门文档负责具体数值；通用规则负责共同语义。具体牌文档不得暗中改写通用术语。
- UI 文档只规定线上表现和技术约束，不应自行新增玩法规则；其中已经明确的真实牌堆、判定实例和服务器权威原则，应回写到正式规则与技术规范。

## 二、整理期来源层级

发生冲突时，按以下顺序处理：

1. 已明确发布日期和生效范围的最新正式补丁；
2. 当前版本通用规则；
3. 当前版本角色/卡牌专门规则；
4. 当前版本注意点和正式问答；
5. UI 与技术设计文档；
6. 旧版本规则、旧注意点和对话式草案。

已经完成的五轮正式裁定必须按其最终记录解释；裁定前问题表只保留历史现场。若旧v1.3.3正文尚未回写而与正式裁定冲突，采用正式裁定。
