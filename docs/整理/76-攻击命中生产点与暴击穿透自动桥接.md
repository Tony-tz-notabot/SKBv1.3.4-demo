# 攻击命中生产点与暴击穿透自动桥接

状态：暴击穿透已从手动事件测试迁移到真实攻击命中生产点。

## 响应命中路径

- 目标完成普通响应并令攻击命中后，`AttackResponseSession`提交`attack.hit`，随后立即派发已经闭环的暴击穿透触发。
- 若打开暴击穿透窗口，会话返回最终权威修订及命中事件、触发选择事件的完整组合；客户端不需要另发“检查触发”命令。
- 闪、近战格挡、防具格挡等令攻击未命中的路径不产生该窗口。

## 无响应命中路径

- 战斗调度器直接判定无需普通响应并提交`attack.hit`时，使用同一暴击穿透事件桥。
- 窗口一旦出现，调度器按现有玩家窗口边界停止，不会继续提前结算伤害段。

## 重叠迁移策略

- 本阶段只自动派发已经完整实现的暴击穿透候选。
- 精致法杖等`attack.hit`触发目前仍由既有专用伤害路径执行；在通用操作解释器支持其全部`consumeLimit/setAttackTag/modifyDamage`语义并移除旧路径前，不重复派发。
- 该按效果族迁移的边界避免同一冻结规则被专用代码和通用触发器各执行一次。
