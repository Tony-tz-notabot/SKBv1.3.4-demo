# 阶段正文调度器第一版实现说明

阶段状态新增`phaseBodyResolved`；处于`body`但正文未完成时，时间轴拒绝推进。

- 准备阶段：有`shieldBroken`标记则清标记且不回盾；否则护盾未满时回复1并记录事件。
- 判定阶段：判定区为空直接完成；不为空则把第一张牌建立为判定结算帧并产生`judgment.requested`，时间轴保持阻塞。
- 摸牌阶段：读取`settings.defaultDrawCount`，最低按0执行，从真实牌堆顶移动到本人手牌并记录`card.drawn`。当前牌堆不足时明确抛出`DRAW_RESHUFFLE_REQUIRED`，尚未伪造重洗。
- 出牌/弃牌阶段：建立只属于行动座位的手动窗口；出牌可选且超时放弃，弃牌为强制且超时随机合法。`finishManualPhase`关闭窗口并完成正文。
- 结束阶段：当前无基础正文，直接标记完成，专属触发留给触发器层。

服务端现有8个测试文件、28项测试及TypeScript构建通过。下一步补可复现随机源、弃牌堆重洗和跨重洗连续摸牌，然后细化弃牌上限报价。
