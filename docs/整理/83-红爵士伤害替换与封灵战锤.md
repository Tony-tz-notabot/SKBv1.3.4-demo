# 红爵士伤害替换与封灵战锤实现说明

状态：服务端实现记录。对应B012—B015及冻结BOSS正文。

## 一、伤害段替换与反噬

红爵士生效期间，每个伤害段依次经过免疫、箱子、普通修正和铁盾；结果仍为正数时才改为1。该替换已统一接入攻击伤害与权威即时伤害管线。

只有特殊生命层、护盾或血量确有实际扣除时，`redLord.actualPositiveDamageCount`才增加。0伤、免疫、箱子防止及死亡未淘汰的空血盾条均不计数。

第四次实际扣除后，在当前伤害段后置事件和濒死检查之前立即令红爵士离槽并清除其铁盾、静滞、装备失效和控制免疫贡献；随后对原持有者施加冰冻与电击。因此反噬不会被红爵士自身的控制免疫阻止。自然到期沿用普通清理路径，不产生反噬。

## 二、每目标攻击画像

脚本攻击入口新增复合攻击能力：同一攻击ID可保存多个目标及每目标独立的`attackTypes`、`damageSegments`和格挡限制。目标仍按攻击者逆时针排序；切换当前目标时原子载入其画像，然后独立处理响应、命中、伤害段和濒死。

这一结构保证复合攻击只有一次攻击提交与一次最终完成事实，同时不会错误地把某一目标的攻击类型或伤害段套给其他目标。

## 三、封灵战锤

红爵士持有者第1、2个后续自己回合轮到时，分别在原准备阶段时机打开一次可选窗口。每个窗口只出现一次；超时按放弃处理且不补发。

使用者可分别选择：

- 至多1名距离4内目标，承受近战伤害3；
- 至多1名距离4内的另一目标，承受激光伤害3，不能近战格挡。

两组都可空选；仅选择一组时只创建该目标组；两组全空时窗口正常解决但不创建攻击。若选择两个目标，它们属于同一次复合攻击，均可独立出闪，并按逆时针逐目标完整结算。

命令执行具备权限、修订、优先权、报价、距离与在场状态重验、目标互异校验及幂等结果缓存。

## 四、验证

测试覆盖正伤改1、0伤不计数、第四次离槽后冰电、两个后续窗口、超时不发动、双目标画像切换、激光禁近战格挡、单组空选与同目标拒绝。服务端41个测试文件、186项测试及TypeScript构建全部通过。
