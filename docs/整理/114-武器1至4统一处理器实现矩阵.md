# 武器1至4统一处理器实现矩阵

状态：2026-08-02 完成第一阶段统一处理器。本文采用严格口径：冻结数据存在不等于可执行；只有服务端真实入口、权威状态变更和行为测试同时存在才计入完成。

## 一、阶段范围

本阶段的“1至4”是武器实现计划的四个通用分块，不是W-01至W-04四张牌：

1. W-01至W-66执行覆盖审计；
2. 通用装备生命周期；
3. 数据驱动的标准攻击参数与攻击方式解析；
4. 通用判定、暴击、追加伤害、状态和伤害后判定节点。

专属展示牌堆、追击、延时复刻、形态转换、金币、诅咒、耐久拆牌、瞄准等复杂正文属于下一阶段的具体机制处理器，不因本阶段完成而宣称整把武器闭环。

## 二、统一处理器覆盖

| 分块 | 生产路径 | 结论 |
|---|---|---|
| 装备/替换 | `weaponEquipment.ts`按冻结`slotType`生成常规槽或第三武器槽报价；替换统一产生离场与失牌事件 | 已完成 |
| 主动丢弃 | 自己出牌阶段可丢弃常规/第三武器；合成实例按实例离场策略返回牌库外 | 已完成 |
| 预选与手刀 | 预选不写领域日志；空槽仅在所有武器槽为空时解析为配置化手刀 | 已完成 |
| 玩家主动方式 | 仅`modeSelection.playerSelectable=true`的公开方式可选；`default`协议别名归一为无显式选择 | 已完成 |
| 自动方式 | 蓄力按实例进度；形态按实例状态；距离档在目标确定后采用覆盖所有实际目标的最小射程档 | 已完成 |
| 标准攻击参数 | 费用、目标数、射程、攻击类型、响应策略、伤害段及散弹/连击维度从冻结数据读取 | 已完成；特殊卡牌费用与血量费用留专用机制 |
| 多目标 | 目标数为上限，少选不倍增；目标队列按逆时针逐个完整结算 | 已完成 |
| 判定时机 | 指定目标后、命中/未命中后且伤害前、未命中、全部基础段后、每个基础伤害次数后 | 已完成 |
| 判定效果 | 判中默认暴击；`createDamage`和`applyStatus`进入统一效果解释器；无论命中与否的规则可显式绕过命中门槛 | 已完成 |
| 追加段 | 不另开普通响应；按时机插入当前目标剩余伤害队列；附加段不会递归触发“每个基础段后” | 已完成 |

## 三、直接行为证据

- W10：有效距离0/1/2分别自动解析`range_0/range_1/range_2`，对应4/3/1个基础次数，自动档不可手选。
- W15：`standard/no_kill`是玩家可选主动方式；不出杀方式仍读取攻击次数费用。
- W50：玩家预选公开`mode_1`后，再由实例`elementForm`解析为火/冰实际模式。
- W16：指定目标后判定发生在普通响应前。
- W02：攻击未命中仍可按冻结规则判定并追加伤害。
- W52：所有基础次数完成后只判定一次，匹配后追加毒`1×2`。
- W55：每个非附加基础次数后独立判定，判定追加段不再次触发自身。
- 通用装备测试覆盖常规槽替换、W14第三武器槽和合成实例主动离场。

## 四、下一阶段边界

下一阶段按武器正文逐项补专属执行器，并更新W001—W053验收状态。优先顺序为：简单攻击后效果/合成与转形→展示牌堆与延时攻击→资源/耐久/诅咒→瞄准和自动攻击队列。只有每张牌的特殊正文均有真实入口及测试后，才可宣称W-01至W-66全部完成。
