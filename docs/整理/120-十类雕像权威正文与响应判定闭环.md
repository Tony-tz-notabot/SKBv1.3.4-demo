# 十类雕像权威正文与响应判定闭环

状态：十类、五色共50张雕像的服务端正文执行已完成。印刷颜色仍由卡牌模板保存；正文按雕像族统一处理。

## 通用生命周期

- 普通雕像经自己的出牌阶段报价进入中央结算区，不消耗可攻击次数；正文前后均保留实例引用和原出牌窗口恢复期限。
- `buildStatueResolutionOffers` 与 `StatueResolutionSession` 提供修订绑定、幂等、目标/方式重验的权威正文入口；后续选择由 `StatueChoiceSession` 管理超时、权限和报价失效。
- 雕像双触判蓝成功后，在正文正常完成或被圣骑士雕像无效时均返回手牌；否则进入弃牌堆。
- 玩法数值、距离、颜色、伤害段与武器方式均从冻结规则数据读取或从已解析武器正文生成，不由客户端决定。

## 十类正文

- 巫师：统一摸牌管线摸配置数量。
- 狼人：距离及盾/血方式配置化；使用共享直接伤害管线，严格按实际盾损/血损回复，0实际伤害不回复，濒死时延后离场。
- 珺之精灵、盗贼：按各自距离选目标；公开区提供具体牌，手牌经权威随机排序后只作为牌背候选；选择时再次重验，分别拆除或获得，初始天赋不是卡牌实例因此不可选。
- 狂战士：修改当前回合剩余可攻击次数，增量读取配置。
- 圣骑士：仅响应其他角色的雕像，提供可放弃的逆时针优先权；连续响应以栈式后进先出结算，可使另一张圣骑士雕像无效，不能进入普通雕像主动使用报价。
- 牧师：展示当前在场角色数张牌，从使用者开始逆时针每人仅一次拿/不拿机会；超时不拿，剩余牌统一弃置。
- 骑士：目标先出杀并交替特殊出杀，主动不出或无杀均失败；胜者可放弃攻击，或选一把当前有效已装备武器。攻击不付杀/次数、不可闪、不可近战格挡、无视防具；蓄力武器在解析副本中强制蓄力0，不修改原实例进度。
- 刺客：按逆时针目标队列，对使用者外所有在场角色建立距离不限远程飞镖复合攻击，每目标独立响应、伤害与濒死。
- 工程师：进入目标判定区并保存最初使用者；判定绿时排入配置化血量伤害并离场，失败则移至逆时针下一在场角色判定区末尾，允许循环至成功、被拆或游戏结束。

## 关键实现边界

- 圣骑士雕像的无效不会撤销此前成功的雕像双触返回标记。
- 骑士雕像只借用武器规则快照，不消耗或变更原武器耐久、蓄力和攻击次数；响应策略明确覆盖普通攻击默认值。
- 工程师雕像使用通用判定卡和干预流程；判定牌与工程师雕像是两个不同实例，判定牌照常弃置。
- 多目标攻击继续使用既有逆时针逐目标完整结算及濒死屏障，不另建并行扣血路径。
