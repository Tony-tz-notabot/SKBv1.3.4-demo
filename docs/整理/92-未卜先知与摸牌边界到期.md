# 未卜先知与摸牌边界到期

状态：R048与一次性摸牌修正跳过到期的服务端实现记录。

## 一、统一受影响摸牌边界

有限次摸牌数量修正不再只在实际抽牌后消费。角色进入受影响的摸牌阶段时，无论该阶段正常完成还是被电击、静滞等其他效果跳过，均消费一次；持续修正不受影响。`draw.modifier.consumed`记录本次边界为`resolved`或`skipped`，保证飞踢等“对应摸牌阶段完成或被跳过后消除”的正式裁定一致实现。

## 二、未卜先知

萨满实际进行摸牌阶段时，服务器先完成商店半价、狂战等全部数量修正并锁定`N=max(0, rawCount)`，随后以未卜先知替换普通抽牌：从真实牌堆顶依次取得`N+2`张到结算区；牌堆中途耗尽时复用统一弃牌堆重洗；双堆不足则展示实际取得的数量。

展示信息只标记给萨满本人，结算区实例保持非公开。服务器建立强制`foresightDrawChoice`窗口，必须从展示牌中选择`min(N, 实际展示数)`张加入手牌，其余按原展示集合进入弃牌堆。`N=0`时仍展示两张并选择零张。非法数量、重复牌、非展示牌或已移动牌均零污染拒绝。

超时属于必须完成且无放弃选项的操作，服务器使用对局可复现随机源选择合法张数，并记录随机历史。成功命令支持幂等重放；选择完成后才消费本次摸牌修正、清理狂战阶段标记并把摸牌阶段正文置为完成。摸牌阶段被跳过时不会创建展示或选择窗口。

## 三、验证

测试覆盖正常`N+2`选`N`、私密结算区、未选牌弃置、`N=0`仍展示两张、跨弃牌堆重洗、非法少选零污染、超时可复现随机、幂等命令及跳过摸牌时一次性修正到期。服务端54个测试文件、232项测试及TypeScript构建全部通过。
