# 武器专属机制完整执行批次

本批次补齐此前严格矩阵中尚未闭环的专属武器正文；冻结 DSL 仍是数值与模式来源，服务端处理器负责实例状态、窗口、队列和生命周期。

## 本批次

- W12：蓄力1/2展示牌堆5/7张，散弹增加额外展示2张，按颜色逐次排入场地1伤害；不创建无意义的攻击响应，展示牌统一弃置并清空蓄力。
- W33：判定颜色可原子替换整组基础伤害段，支持白6、绿毒4、蓝场地4并冰冻、橙火4、红真实4。
- W54：标准方式与金币方式共享模式解析；金币方式接受实体白/红金币资源，不耗杀或攻击次数，费用进入结算区并在攻击收尾离场，命中后正常进入专属判定。
- W57：按当前血量自动选择方式；血量至少2时以非伤害/非回复的数值修改支付1血，血量为1时退回正常杀与次数费用。
- W58：主动陨星以一张杀和一次攻击次数为总费用，从使用者起逆时针对全部在场角色创建同一次复合场地攻击；CD=2以三个自己的准备阶段计数。
- W61：伤害次数读取公开耐久；命中后先开“正常伤害/改为拆牌”可选窗口，超时正常伤害；拆牌令本次伤害段为空并扣1耐久，耐久0按实例来源离场。
- W56：2发、散弹增加时3发弹头分别构成独立0伤远程攻击与响应；按目标累计命中，3发直接诅咒，2发和1发依次进入可干预判定。诅咒立即生效，到目标下个准备阶段前到期，攻击解析强制改用不占槽的临时W32。
- W64：首次瞄准只支付杀和次数而不发动攻击；有瞄准时，出牌阶段获得的每一点攻击次数都由锁定循环逐点消费，在目标仍在距离3内时各创建一次无杀激光攻击，否则只消费次数；可出杀取消瞄准。
- W66：0伤命中后为目标创建不进入任何区域的临时金币并立即开使用/放弃窗口；可交给目标有效的W54金币方式，作为外层攻击完成后的子攻击结算，未使用即消失。

## 严格边界

- 0伤命中仍产生`attack.hit`，但不会产生实际伤害；W56命中计数和W66临时金币均依赖命中事件而非伤害事件。
- W61拆牌在伤害前替换整次伤害段，不伪造成闪避或未命中。
- W56临时手枪不创建实体卡、不占装备槽、不可移动；诅咒到期后攻击解析自然恢复原预选武器。
- W66临时金币不进入手牌、结算区或弃牌堆。
