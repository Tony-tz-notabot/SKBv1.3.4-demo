# 真实应用层与联机链路实现说明

## 阶段边界

本阶段开始落实完整可玩链路中的服务端应用层、权威受众投影、Vue真实连接及端到端恢复。武器总验收与跨规则组合验收依作者要求后置，不计入本阶段前置条件。

## 已实现

- 房间创建、加入、座位、准备、设置、房主、选角、队伍/全体聊天与开局状态转换。
- JSON状态原子持久化；服务重启后房间与权威对局恢复，连接状态重置为离线。
- `/ws` WebSocket入口、客户端持久用户ID、心跳、自动重连及重连后最新受众快照。
- 按用户/队伍过滤房间和游戏聊天；本人选角候选、手牌及操作报价不向其他受众投影。
- 开局重摸、武器预选、阶段结束/弃牌、攻击响应、濒死、判定和通用触发窗口的首批统一命令路由。
- 选角、重摸和上述常用手动窗口的服务器超时推进。
- Vue生产与普通开发模式默认连接真实服务器；仅`?mock=1`使用开发模拟服务器。
