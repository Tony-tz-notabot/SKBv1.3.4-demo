## 编码分类

| kind | 用途 |
| --- | --- |
| `pipeline` | 固定执行顺序，如阶段、攻击、判定、濒死、响应栈 |
| `trigger` | 监听事件后创建效果 |
| `replacement` | 在请求事件提交前替换 |
| `invariant` | 始终成立的合法性、选择器或标签约束 |
| `viewPolicy` | 隐藏信息和客户端投影视图 |
| `configuration` | 版本配置和房间覆盖 |
| `securityPolicy` | 权威命令、随机、回放、快照及重连 |
