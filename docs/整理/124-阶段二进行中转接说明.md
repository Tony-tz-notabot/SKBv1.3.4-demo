## 四、E2E 排错现场

真实 WS 链路已推进到：

建房 → 四人加入 → 准备 → 选角 → 四人重摸 → 正式对局 → 主机预选空武器槽 → 手刀攻击报价出现。

当前失败点：

- 第一次攻击后，目标客户端收到 `attackResponse` 快照；
- `responseSnap.interaction.prompt.promptId` 与权威 `pendingWindows[0].promptId` 一致；
- pass 的 `offerId` 为 `offer:attack-response:pass:attack:13:1`；
- 提交后服务端返回 `OFFER_HANDLER_NOT_REGISTERED`。

排查方向：

1. 检查 `server/src/app/gameService.ts` 中 `attackResponse` 核心分支是否实际命中；
2. 检查 `AttackResponseSession.handle` 对 pass 命令的字段要求；
3. 检查 `executeWindow` 是否意外拦截，或 `window` 查找在命令进入时已被 tick 关闭；
4. 完成后再继续第二次击杀并验证 `winnerTeam`。
