# 状态施加事件与冰盾触发迁移

## 一、事件事实补全

状态成功施加或刷新时，事件现在同时携带`targetRef`、`sourceSeat`、`result`与可选`attackId`。状态被免疫或因规则阻止时仍只产生`status.prevented`，不会伪造成功事实。

## 二、冰盾迁移

已删除`status.ts`中按`talent.ice_shield`牌名追加毒伤的专用分支。冻结包的`status.applied`触发现在经统一触发注册表匹配：来源是冰盾控制者且冰冻结果为施加或刷新时，创建1点附加毒属性效果伤害。

- 冰冻由当前攻击产生时，通用`createDamage`操作把毒伤追加为当前攻击的效果伤害段，维持原攻击内时序；
- 攻击外施加冰冻时，伤害进入`immediate.damagePipeline`计划队列；
- 被冰盾或元素本源免疫的冰冻没有成功状态事件，因此不追加毒伤；
- 普通装备失效会关闭装备冰盾触发，初始天赋冰盾继续有效。

## 三、验证

判定武器真实造成冰冻后会经过统一触发并追加毒伤；攻击外状态触发继续由共享直接伤害管线消费。服务端37个测试文件、163项测试与TypeScript构建全部通过。
