# 标准攻击、响应、伤害与濒死管线第一版

本阶段在通用动作/费用/目标骨架上接入第一条可运行的标准攻击主链。

## 已实现

- 武器预选为私密状态提交，不产生领域日志；槽位和主动模式由冻结武器数据校验。
- 空槽仅在全部武器槽为空时解析为配置化手刀；存在失效武器也不能使用手刀。
- 准备阶段从设置重置可攻击次数；手刀参数、杀模板前缀和次数键均由版本设置读取。
- 冻结武器模式可解析目标数、射程、杀/次数费用、响应策略和伤害段；蓄力武器按实例进度选择档位。
- 攻击提交原子支付杀和次数、清理蓄力、建立目标队列；多目标统一按攻击者起始的逆时针顺序规范化。
- 出牌窗口在攻击期间挂起，攻击及嵌套濒死完成后以新提示恢复，避免两个优先权窗口并存。
- 普通闪抵消整次攻击；近战武器可格挡合法远程攻击且不离开装备；激光、场地和装备失效时不报价近战格挡；场地攻击不开放普通闪窗口。
- 伤害段逐段处理铁盾、无敌、蓝盾溢出、护盾/血量路由、破盾和实际损失事件；0伤不产生收到伤害。
- 死亡未淘汰且无血盾条时仍产生收到伤害，三个实际损失均为0。
- 同一目标全部伤害段后立即进入濒死；救援按当前回合玩家起逆时针取得机会，连续放弃后死亡，药水与合法号角可以救援。
- 救援/淘汰结束后才恢复原攻击并继续下一目标；基础淘汰和阵营胜负检查已接入。
- 战斗调度器连续推进到响应窗口、濒死窗口、恢复的出牌窗口或战斗完成。

## 当前边界

- 判定型武器、暴击、判定替换、圆盾/盾牌杀无效和具体防具能力尚未接入。
- 动态武器费用和复杂自动模式如果通用解释器无法确定，会明确返回`REQUIRES_RULE_RESOLVER`，不会擅自选档。
- 特殊生命层、伤害替代器、元素修正和死亡替代仍需在后续管线层实现。
