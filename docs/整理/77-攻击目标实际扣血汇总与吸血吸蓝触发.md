# 攻击目标实际扣血汇总与吸血吸蓝触发

## 一、实现范围

本轮将冻结规则中的`talent.life_steal`（吸血）与`talent.mana_siphon`（吸蓝）接入标准攻击伤害生产点。

- 统计事实使用`actualHpLoss`，不使用拟议伤害、最终伤害、护盾损失或特殊生命层损失；
- 统计域为“同一次攻击、同一个目标”；一个目标的全部伤害段结算完后统一判断；
- 累计实际血量损失至少2点时触发；同一来源对同一攻击目标最多触发一次；
- 多目标分别统计，因此每个达到阈值的目标均可各触发一次；
- 死亡但未淘汰且没有血盾条的角色仍可收到伤害事件，但`actualHpLoss=0`，不会产生吸血或吸蓝收益。

## 二、执行边界

`damage.ts`在产生`attack.target.after`汇总后、检查该目标是否进入濒死前，将汇总事实交给冻结触发注册表。只迁移吸血与吸蓝两个已经具备完整通用操作语义的家族，避免重复派发现有专用实现尚未移除的触发。

`consumeLimit(scope=perTargetPerAttack)`不写入跨攻击的玩家次数字段，而是在当前攻击上下文记录由触发、来源、攻击和目标共同组成的使用键。攻击结束后该键随攻击上下文一同消失。

## 三、验证

- 两个1点血量伤害段累计达到2点时，吸血只回复一次；
- 仅1点实际扣血、仅损失护盾，以及攻击死亡无血盾条角色均不触发；
- 同一次多目标攻击中，两个目标各损失2点血量时吸蓝分别摸一张；
- 服务端37个测试文件、163项测试全部通过，TypeScript生产构建通过。
