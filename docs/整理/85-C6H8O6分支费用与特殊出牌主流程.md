# C6H8O6分支、费用与特殊出牌主流程实现说明

状态：服务端阶段实现记录。B024—B028及已知技能转换已实现，C6H8O6主流程闭环。

## 一、分支提交边界

两分支均先检查使用窗口、BOSS额度、指定牌型、攻击次数及分支专属合法性，全部通过后才在同一事务内消耗1次攻击次数并提交BOSS使用。失败不会移动牌、扣次数或占BOSS额度。

激光扫射把牌移入结算区且不占BOSS槽；定点轰击要求距离1目标以及空BOSS槽，或死亡前可替换的钢铁破浪者号，并把目标、指定牌型和待触发状态保存于C6实例。

## 二、激光扫射

除使用者外的在场角色按逆时针依次获得一次特殊出牌窗口。实体【杀】/【闪】候选由本人手牌生成；明确视为打出的技能转换也进入同一候选表。提交时重验并原子支付实体牌或技能费用；超时或放弃记为未打出。

当前已接入游侠“翻滚”（一张橙色手牌视为【闪】）与刺客“刺客信条·闪”（两张同色手牌视为【闪】）。游侠的下一自己回合【杀】攻击必定暴击授权在该回合开始时生效并于回合结束清除；刺客的防御距离+1持续到其下个准备阶段开始前，且其独立限次在该节点重置。

所有角色结果收集完成前不创建伤害。收集结束后按未打出人数锁定2/3/5，向未打出者按逆时针排入直接激光普通伤害；每名角色的伤害与濒死完整处理后再处理下一名。全部完成后恢复原使用者的出牌窗口。

## 三、定点轰击

目标下一个出牌阶段`phase.after`触发；正常结束、跳过和替换边界均监听同一时间点。触发时连续创建两次指定牌特殊出牌窗口，第二次只在第一次完成后出现。

0/1/2次成功分别排入5/2/0点直接场地普通伤害。请求完成后C6进入弃牌堆。目标在触发前淘汰或离场时立即取消并弃置；死亡未淘汰仍属于在场目标，继续触发。

## 四、恢复调度

即时伤害队列新增`resumePlayWindow`稳定操作：激光扫射产生的全部直接伤害和嵌套濒死处理完毕后才恢复出牌窗口，防止玩家窗口阻塞尚未结算的伤害。

## 五、当前验证

测试覆盖费用失败零污染、三人收集后统一伤害、单人成功后的3点映射、定点槽位检查、双请求、0/1/2张映射、目标离场取消、游侠转换与跨回合暴击授权，以及刺客同色双牌、独立限次和防御距离到期。服务端44个测试文件、198项测试及TypeScript构建全部通过。
