# 拳击柱惯性按来源累计与结束阶段反击

状态：R019、R020服务端严格执行闭环。

## 一、累计口径

- 每个实际伤害次数完成生命路由后，以明确伤害来源座位分别累计。
- 计入拳击柱额外血量层、普通护盾和普通血量的实际损失；大史莱姆等其他特殊层损失不误算为拳击柱自身惯性。
- 最终0伤、免疫、防止、铁盾完全抵消和直接修改数值均不累计。
- 无来源直接伤害保留`sourceSeat=null`，不得错误归入1号座位。

## 二、反击节点

- 每名来源进入自己的结束阶段时，读取该来源尚未反击的累计值x。
- 权威状态立即保留`x mod 3`，并按顺序创建`floor(x/3)`个独立的1点场地真实直接伤害计划；每次伤害及濒死完整处理后才继续下一次。
- 来源死亡但未淘汰时仍创建反击；其没有血盾条，实际损失为0，但仍经过收到伤害类事件语义。
- 来源已淘汰时清除该来源累计，不创建反击。其他已淘汰来源的陈旧累计也在结束阶段检查时清理。

## 三、验证

新增测试覆盖额外血量、护盾、血量三层累计、每3点一次真实伤害、余数保留、死亡未淘汰仍触发、淘汰清除及无来源伤害隔离。服务端73个测试文件、310项测试及TypeScript构建全部通过。
