# SKB v1.3.4角色规则DSL回写说明

状态：角色规则结构化第一稿完成。

`rulesets/v1.3.4/character-rules.json`包含：

- 25名角色；
- 57个稳定能力模板；
- 50条角色规则；
- R001-R050完整且唯一映射。

57个能力由25个初始天赋和32个技能/子能力组成。陷阱大师的炸弹人、炸弹防御、炸弹引爆按三个独立能力编码，便于分别绑定主动窗口、伤害修改窗口和准备阶段窗口。

## 结构约束

- 每个`abilityId`唯一并反查唯一`ownerCharacterId`。
- `characters.json`中的`initialTalentIds`和`skillIds`由能力目录生成并校验一致。
- 跨角色共同规则使用`characterId: "*"`；当前R016反弹链上限同时覆盖道士和刺客。
- 每条角色规则均绑定监听事件、效果操作、能力ID、测试ID和验收断言。
- 所有角色数值与阶段节点来自v1.3.4角色单一正文，不读取旧角色稿。

## 当前边界

这是服务端解释器可消费的规则描述；尚未实现真实运行时、事件队列、状态存储和网络协议。Vue客户端只能读取服务端投影视图并发送操作意图。
