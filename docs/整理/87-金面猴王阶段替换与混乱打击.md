# 金面猴王阶段替换与混乱打击实现说明

状态：服务端阶段实现记录。B038—B042主流程已实现。

## 一、阶段替换

金面猴王激活后的第1、2个自己回合，仅在摸牌阶段或出牌阶段本来会实际发生时，将该阶段替换为混乱打击。其他效果已经令阶段跳过时不触发替换。

替换发生时先记录`phase.replace`并开启真实颜色判定；替换效果尚未完成前不产生该阶段的`phase.after`。白色、主动放弃、超时放弃或混乱打击的完整攻击链结束后，才统一完成阶段after、状态到期与出牌阶段结束相关延时检查。

## 二、判定与目标

颜色判定使用真实牌堆、弃牌重洗和通用判定干预优先权，不属于暴击判定。白色直接结束且不开放目标选择；绿、蓝、橙、红分别读取冻结DSL的攻击模板和射程，生成当前合法在场目标报价。目标选择可放弃，超时默认放弃；提交时重验报价、权限和目标。

## 三、四种攻击

- 绿·大菠萝：距离3，远程普通伤害`1×3`；
- 蓝·石蟹：距离2，近战普通伤害`1×3`；
- 橙·炸药包：距离1，场地普通伤害2，命中后进行红/橙追加判定，成功加入1点附加火伤；
- 红·空中支援：距离4，场地普通伤害2，命中后施加电击。

四者均是不耗【杀】和攻击次数的非武器脚本攻击，复用完整响应、命中、伤害段、状态、濒死及派生反击管线。场地模板无视防具且不开放普通闪/近战格挡。橙色追加判定即使命中段成为0仍发生。

## 四、验证

测试覆盖实际阶段替换、其他效果跳过时不替换、阶段after延后、白色无攻击、绿色`1×3`、主动/超时放弃、橙色追加火伤判定和红色命中电击。服务端46个测试文件、207项测试及TypeScript构建全部通过。
