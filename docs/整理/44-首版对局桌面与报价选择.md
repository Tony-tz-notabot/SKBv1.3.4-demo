# 首版对局桌面与报价选择

## 一、对局桌面

Vue客户端现已实际消费 `GameSnapshot`，提供首版四方桌面：

- 按 `viewer.seat` 旋转四个座位，本地玩家固定在下方；
- 显示当前轮次、行动座位、六阶段轨道和服务器标题；
- 显示角色图片、队伍、在线状态、生命、护盾、铁盾、生命状态、状态列表、手牌数量和公开装备；
- 显示牌库数量、有限重叠的弃牌顶、中央公开牌及自己的完整手牌；
- 卡牌和角色主图均通过规则资源键加载仓库 `assets/`，缺图继续使用既定占位降级。

## 二、服务器报价选择

页面不会从牌面自行推断可操作性。当前操作完全来自 `InteractionView.offers`：

- 选择一个报价后，只高亮其合法来源牌和合法目标；
- 卡牌与目标选择按 `SelectionSpec.min/max/distinct/legalRefs` 收集；
- 未满足全部选择数量时禁用确认；
- 提交只包含服务器给出的 `promptId/offerId`、当前 `stateRevision` 和选择结果；
- 没有真实 `promptId` 时禁止提交，客户端不伪造自由操作窗口；
- 无选择要求的报价可直接提交。

当前已实现 `cards/targets` 两类视觉选择。`option/number/color/mode/confirm` 将在下一阶段用同一规范补齐。

## 三、开发模拟

新增 `game` 开发场景，包含四名角色、实际角色/卡牌素材、血盾、状态、装备、弃牌、私有手牌和三个服务器报价。模拟命令仍经过游戏协议网关，并以新修订快照回写；结束阶段报价可推进到弃牌阶段。
