# 牧师祈祷共享额度与希望手牌费用

状态：R017、R018服务端严格执行闭环。

## 一、祈祷

- 自己出牌阶段可将一张红色手牌作为祈祷，选择一名在场且具有血量条的角色回复2血。
- 濒死救援窗口会把合法红色手牌单独报价为祈祷；它与实体药水明确区分，固定回复2血，不受强力药水加成。
- 主动和濒死响应共用`priest.prayUsed`额度；任一入口成功后另一入口立即不再合法。
- 额度在牧师准备阶段开始前重置，准备阶段被跳过仍重置。
- 提交时重新验证技能、额度、手牌区域、印刷颜色、窗口、目标和状态修订；失败不移动牌。

## 二、希望

- 希望只报价牧师手牌区内的白色牌；同色装备区、判定区或其他区域牌均不能支付。
- 自己出牌阶段限一次，成功后弃置所选白色手牌，使一名合法在场角色回复1血。
- 回复量不受强力药水加成。

## 三、验证

新增测试覆盖希望的手牌区域限制、主动祈祷共享额度及准备重置、濒死祈祷独立报价、固定2点回复和强力药水不加成。服务端72个测试文件、308项测试及TypeScript构建全部通过。
