# 攻击无效、圆盾与必定暴击保留实现说明

## 一、【杀】无效边界

- 攻击者先完成目标选择、【杀】支付与攻击次数支付，再检查【杀】无效。
- 盾牌在装备效果有效且攻击未无视防具时，令白色或蓝色【杀】无效。
- 圆盾使用后秘密保存所选白、蓝、橙、红颜色之一；匹配该色【杀】时令攻击无效。
- 无效后，已支付的【杀】进入弃牌堆，攻击次数不返还，攻击不产生正式 `attack.commit`。
- 蓄力武器只在攻击正式提交后清零；攻击提前无效时保留原蓄力进度。
- 无效攻击结束后恢复新的出牌阶段窗口。

## 二、圆盾持续期与公开

- 圆盾每个自己的出牌阶段限发动一次。
- 颜色在首次匹配前仅保存在权威私密状态；首次令攻击无效后标记为已公开并产生公开展示事件。
- 效果到使用者下个准备阶段开始前到期；进入该边界时先清除，再处理准备阶段，即使准备阶段被跳过也会清除。
- 多名角色分别发动的圆盾锁可以并存，按各自来源与持续期保存。

## 三、必定暴击保留

- 必定暴击使用结构化授权实例保存适用攻击类型、消费策略及到期点。
- 类似号角的授权只在一次合法武器攻击正式提交时消费。
- 【杀】被盾牌或圆盾提前无效时，授权不消费。
- 到期仍未消费的当前回合授权在回合结束时清除；“下个回合结束”授权先进入待生效周期，再于下一次所有者回合结束清除。

## 四、验证

- 覆盖盾牌无效、装备失效、圆盾首次公开、跳过准备仍到期、蓄力保留及必定暴击不被无效攻击消费。
