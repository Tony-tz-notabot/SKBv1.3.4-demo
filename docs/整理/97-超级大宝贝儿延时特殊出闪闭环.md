# 超级大宝贝儿延时特殊出闪闭环

## 已实现范围

- `SP-09`只能在自己的出牌阶段从手牌使用，进入使用者判定区，并在实例上保存持续来源座位。
- 到该角色下个判定阶段时，只有牌仍在判定区才触发；触发前被拆除则不产生效果。
- 响应顺序从来源角色开始逆时针覆盖所有当前在场且未淘汰角色。所有人完成特殊出闪或放弃后，才进入伤害阶段。
- 特殊出闪复用统一特殊出牌语义：允许实体【闪】及合法技能闪，不允许防具响应；该请求不属于攻击。
- 未出闪者按既定顺序逐人受到3点直接血量伤害，每名目标的濒死流程完成后才处理下一人。
- 血量伤害阶段结束后重新读取当前在场角色；来源外各目标依次受到火1、毒1。同一目标的两段元素伤害处理完成后才检查濒死。
- 全部效果完成后，仍在判定区的牌进入弃牌堆，判定阶段正文可以继续。

## 验证

- 覆盖使用与持续来源、全员先响应、逐目标血量伤害、嵌套濒死、元素阶段重算目标、火毒同目标成组及触发前拆除。
- 服务端全量回归：61个测试文件、271项测试通过；TypeScript构建通过。
