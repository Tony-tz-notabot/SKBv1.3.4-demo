# SKB 第三轮武器正式裁定（进行中）

状态：历史过程记录。第三轮现已全部完成，最终状态见 `09-第三轮武器正式裁定.md`。

## 一、通用裁定

1. 多目标武器标注的目标数是可选择的上限。每个目标分别获得牌面写明的一份完整效果；少选目标不会把未使用份额叠加给已选目标。例如陨星炮“7，2目标”选择一人时只对该人造成7，不造成14。
2. 所有通过合成创建的产物实例，无论该模板初始牌库数量是否为0，离开使用/装备流程后都返回牌库外，不进入普通弃牌堆或重洗。
3. 武器攻击中只要存在判定且结果“判中”，除非武器明确写不算暴击，否则该次攻击视为暴击。必定暴击可以指定该次判定的成功结果。
4. 若一次判定列出多个成功颜色，必须保留这些颜色的精确表述；它们同时用于判断判中、暴击及具体效果，不能笼统改写成“非白”等，除非原规则如此定义。
5. 光剑土豪金距离2档的近战与远程伤害只进行一次响应；一次成功响应抵消整次攻击全部伤害段。
6. 攻击参数未单独标注攻击方式时，继承武器类型；攻击参数单独标注时，以该次攻击参数为准。

## 二、具体武器裁定

### W-12 激光雨

- 蓄力0保持距离2、激光伤害2。
- 蓄力1、2删除原先的“场地0”第一段，不创建0伤攻击或响应窗口。
- 使用蓄力1/2时直接执行翻牌及场地伤害效果：蓄力1展示5张，每张蓝/红造成1点场地伤害；蓄力2展示7张，每张蓝/橙/红造成1点场地伤害。
- 仍按使用武器的正常费用消耗【杀】和攻击次数。

### W-16 猎人弓

蓝色判定属于判中，因此该次攻击视为暴击；必定暴击可以指定蓝色结果。

### W-33 妙妙枪

妙妙枪的指定目标后判定属于暴击判定。各颜色结果按原牌面保留；判中结果使攻击视为暴击。

### W-37 光剑土豪金

距离2档的近战 `2×3` 与远程 `2×3` 属于同一次复合攻击，只响应一次。该次攻击成功出闪或被合法近战格挡时，整次攻击全部伤害段被抵消。

### W-42 重铸的圣剑

采用全局攻击方式继承规则。该牌武器类型虽含近战/散弹，但本次攻击参数明确写场地，因此按距离2、场地散弹 `2×2` 处理；散弹增加后为 `2×3`。

### W-49 冰与火之鹰

牌库原有实例仍属普通牌库。通过合成额外创建的冰与火之鹰实例离场后返回牌库外，不会永久增加普通牌堆数量。

### W-54 撒币枪与金币

- 金币是基础牌，而不是公开资源计数。
- 金币可以作为已有基础牌被正常使用，也可以由进水的箱子生成并自动打出。
- （历史待办，现已解决）金币加入初始牌库共2张，白、红各1张；见第四轮正式裁定 P01。
- 撒币枪特殊攻击消耗一张金币，不使用【杀】且不消耗攻击次数。
- 特殊攻击判定仍严格保留“绿、蓝、橙、红”四种成功颜色；这些颜色同时影响判中和暴击判断。

### W-56 阿努比斯的权杖

诅咒造成后立即生效，持续到被诅咒者下个准备阶段开始前；到达该节点时结束，不覆盖其下一个完整回合。

### W-57 死神之息

- 原“血量≥2时不消耗可攻击次数”为错误文本，删除。
- 血量≥2时：不打【杀】，但正常消耗1次可攻击次数，并修改血量-1作为费用，距离3、伤害4。
- 血量=1时：正常打【杀】并消耗1次可攻击次数，不扣血，距离2、伤害3。

### W-58 陨星杖

- 发动仍视为攻击，不是直接造成伤害。
- 使用时正常打出【杀】并消耗1次可攻击次数，同时进入 CD=2。
- 对所有角色（包括自己）按逆时针逐个发起3点场地攻击；依场地规则不开放普通响应。

### W-62 地下水与 W-63 肉

- 每回合第一次尝试使用该武器就计为第一次使用，即使【杀】被提前无效、攻击未正式发起也计数。
- 从第二次开始，包括第二、第三、第四及以后所有次数，均不消耗可攻击次数，但仍需【杀】。

### W-64 激光鱼

- 第一次指定目标时只建立瞄准，不立即发起激光鱼攻击；仍消耗一张【杀】和1次可攻击次数。
- 若支付瞄准费用后仍有剩余攻击次数，则剩余次数立即按锁定规则转化为对瞄准目标的激光鱼攻击。
- 后续自动攻击规则已按 WQ49 初判正式采用，详见最终裁定。

### W-66 进水的箱子

- 攻击参数改为距离9、场地伤害0。
- 正常打出【杀】并消耗1次可攻击次数，可选择包括自己在内的一名目标。
- 结算时给予目标一个临时金币。该金币不进入手牌，目标必须立即选择一种合法金币用途并自动打出；可用于撒币枪攻击，也可用于未来新增的其他金币用途。
- 若没有合法用途或目标放弃使用，临时金币在该结算结束时消失。
