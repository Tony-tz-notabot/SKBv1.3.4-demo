# 房间、选角与聊天交互说明

状态：首批房间操作已接入命令系统。

## 一、已接入操作

- 大厅：创建房间、输入六位房间号加入；
- 房间：准备/取消准备；
- 选角：点击候选预选、确认锁定；
- 房间与选角：全部/队伍聊天。

页面只提交表单意图。`roomActions.ts`从当前服务器快照读取`roomId`和`roomRevision`，页面不能自行提供或修改修订号。

## 二、反馈

- 命令发出后显示待服务器确认数量；
- 接受后清除对应等待状态；
- 拒绝时显示`reasonCode/messageKey`；
- `refreshRequired=true`时明确提示等待刷新快照；
- 新操作会清理上一次拒绝提示，玩家也可手动关闭。

## 三、开发模拟

模拟服务器支持创建/加入、准备、预选、锁定和聊天，并返回增加修订号的新`RoomSnapshot`。模拟快照仍经过正式Ajv与跨字段验证，不允许直接修改Vue Store冒充服务端结果。

## 四、隐私与聊天

- 选角操作只使用当前玩家私密候选ID；
- 他人候选和锁定角色在统一公开前仍不进入页面数据；
- 聊天命令只提交`all/team`频道，不提交接收者列表；
- 队伍消息最终收件权限仍由服务器按固定座位队伍执行。

## 五、验收

- 通信状态机4项测试通过；
- TypeScript类型检查通过；
- Vite生产构建通过；
- 浏览器确认角色预选产生等待反馈、聊天回写新快照且无控制台错误；
- 锁定触发已改为显式脚本函数，避免模板短路表达式的不稳定行为。
