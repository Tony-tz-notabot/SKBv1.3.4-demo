# 角色详情与资源图片接入说明

## 本轮范围

Vue 客户端的私密选角页已接入角色主图、详情侧栏和缺图降级。该实现只负责显示服务器投影，不在客户端解释或执行角色规则。

## 详情入口

- 候选卡右下角提供明确的“详情”按钮。
- 桌面端可右键候选卡打开详情。
- 触屏或指针设备可长按约 480ms 打开详情；长按完成后不会误触发角色预选。
- `Escape`、关闭按钮或点击遮罩空白处关闭详情。
- 不打开详情时，候选卡仍显示名称、难度、生命、护盾、初始天赋标识和技能标识。

详情侧栏目前严格使用 `CharacterCandidateView` 已公开字段。完整规则长文本应后续扩展为服务器下发的结构化详情投影，不允许 Vue 直接读取 Markdown 或解释规则 DSL。

## 资源解析

- `src/resources/resourceResolver.ts` 是客户端唯一资源键转图片地址入口。
- 解析顺序为：具体资源 → `fallbackResourceKey` → 类别占位图 → 通用占位图。
- 同时兼容当前协议示例的 `character.knight.portrait` 和规则资源表的实体映射，不在页面硬编码中文文件路径。
- Vite 将仓库 `assets/` 作为静态公共目录；生产构建会复制实际素材。
- 图片请求失败会在组件内继续降级，不显示浏览器破图。
