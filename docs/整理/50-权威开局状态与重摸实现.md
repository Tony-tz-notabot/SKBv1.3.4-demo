# 权威开局状态与重摸实现

## 一、状态边界

服务器将正式开局前建模为独立`setupRedraw`生命周期，不冒充准备阶段。创建请求必须提供`firstSeat`和随机种子；首个行动座位由房间/开局协调层决定，规则引擎不自行猜测。

## 二、确定性初始化

- 从冻结`deck.json`创建337个唯一卡牌实例。
- 使用显式种子洗牌，并把洗牌前候选与最终顺序写入服务器私有随机记录。
- 从`firstSeat`开始按逆时针座位顺序，每人从牌堆顶获得配置的4张；发牌后牌堆剩321张。
- 同一规则包、种子和输入产生相同实例与牌序，可用于回放。

## 三、重摸事务

每个座位保存`decided/used`。选择重摸时，在一个原子事务内完成：验证窗口与次数→移出全部原手牌→原牌正面进入弃牌堆→从牌堆顶获得4张→记录领域事件→提交新修订。放弃只记录决定，不改变手牌。

四人均完成或按超时策略放弃后，生命周期切换为`inProgress`并产生`game.start`。重复选择和窗口关闭后的命令均被拒绝；事务失败不会留下部分弃牌或部分摸牌。

## 四、验证

服务器现有3个测试文件、9项测试通过，覆盖冻结加载、篡改拒绝、事务提交/回滚、确定性洗牌、337实例、初始4张、弃4摸4、原牌不返回及全员完成后开局。
