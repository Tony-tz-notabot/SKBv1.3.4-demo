# 暗黑大骑士黑剑制造与常规攻击

状态：服务端B029—B031实现记录。与文档68的最后一击合并后，暗黑大骑士正文主流程已闭环。

## 一、制造黑剑

只有激活中的暗黑大骑士持有者可在自己出牌阶段正文中发动，每个出牌阶段最多2次，黑剑标记上限2。满2时在事务开始前拒绝，不扣血、不降上限且不改变任何状态。

合法发动严格按“当前血量-1→血量上限-1→检查濒死→获得1黑剑”的语义提交。两次数值变化是修改而非伤害，不进入攻击伤害收益统计。若发动后血量不大于0，当即进入统一濒死栈；本次黑剑仍已获得。

## 二、黑剑攻击

三种攻击均消耗1黑剑，不消耐【杀】且不消耗攻击次数，因此暗黑大骑士将可攻击次数设为0时仍可发动。目标在提交时重验在场、未淘汰与实际距离。

- 刺击：距离4，远程/散弹，`2×2`，无视防具，不可近战格挡，可闪；
- 斩击：距离2，近战伤害4，无视防具，按普通近战攻击响应；
- 锤击：距离2，场地伤害2，无视防具，不开放普通闪窗口，命中后施加电击。

攻击提交时挂起原出牌窗口，保留其截止时间，并复用标准响应、伤害段、濒死、状态与攻击收尾管线。

黑剑上限、每阶段制造次数、三种模式的费用、射程、攻击类型、伤害量、段数、防具/格挡标签和命中状态均从`boss-rules.json`加载，服务端只保留稳定模式ID与执行语义。
