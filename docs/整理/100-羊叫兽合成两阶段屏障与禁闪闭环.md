# 羊叫兽合成、两阶段屏障与禁闪闭环

## 合成与实例生命周期

- 自己的出牌阶段持有网瘾少年和网瘾少女时，服务器提供主动合成报价；提交时必须分别选择一张仍在手牌的精确材料。
- 两张材料以`synthesizeConsume`进入弃牌堆，随后创建羊叫兽实例并加入使用者手牌，不自动使用。
- 生成实例携带`generatedExitZoneRef=outsideDeck`；使用结算、弃置等离开普通流通的动作均重定向至牌库外。

## 阶段一

- 羊叫兽只能在自己的出牌阶段使用。使用后挂起原出牌窗口，使用者外在场角色依次完成特殊出闪，全部响应收齐前不造成伤害。
- 合法出闪包括实体牌、合法技能和双截棍/光剑土豪金判定防具；判定失败后可继续响应，但本次请求不能重复尝试该防具。
- 对每名未出闪者按顺序造成2点直接普通感电伤害，随后立即施加“当前回合不能以任何方式出闪”，再检查并完整处理该目标濒死。
- 禁闪同时关闭普通攻击手牌闪、判定防具闪以及所有复用统一特殊出牌模块的实体/技能闪；近战格挡不是出闪，不受该限制。
- 每个禁闪实例记录明确`currentTurn.end`持续期；当前全局回合结束时统一移除，即使目标之后的阶段被跳过也不延长。

## 阶段屏障与阶段二

- 阶段一未响应者的伤害、禁闪及嵌套濒死全部完成后，才启动阶段二；中间不恢复出牌窗口，也不开放无关可选操作。
- 阶段二调用网瘾少年的完整效果，但创建全新的独立响应收集，阶段一是否出闪不沿用。
- 阶段二按其自身未响应人数`x`逐目标造成`x`点感电伤害。完成后羊叫兽返回牌库外，并只恢复一次原使用者出牌窗口。

## 验证

- 覆盖精确双材料、生成实例离场、阶段一全响应屏障、固定2点伤害、全方式禁闪、濒死暂停、独立阶段二、人数伤害、回合末到期及最终窗口恢复。
- 服务端全量回归：65个测试文件、286项测试通过；TypeScript构建通过。
