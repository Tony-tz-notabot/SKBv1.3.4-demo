# 普通特殊牌与鲜血诅咒执行闭环

状态：服务端第一版实现说明。规则来源为 `20-v1.3.4非BOSS牌规则正文.md`、`21-v1.3.4非BOSS牌测试清单.md`、第一轮与第四轮正式裁定及冻结 `nonboss-rules.json`。

## 一、本轮闭环范围

- P043 死亡笔记：自己的出牌阶段使用，距离不限，所有在场未淘汰角色均可选且允许选择自己。有正护盾时把护盾修改为0，否则把血量修改为1；两者均为数值修改，不创建伤害、破盾或濒死事件。
- P045 号角小队：打出后持续到使用者下个准备阶段开始前。仅一般武器攻击且实际支付至少一张【杀】时免除攻击次数；手刀和显式消耗攻击次数的能力/模式不受影响。
- P049 鲜血祭坛：按冻结数据依次令血量上限-2、将超过新上限的当前血量压到新上限、再令当前血量-2。随后立即检查濒死；效果不进入伤害管线。
- P050 鲜血诅咒：祭坛持续期在使用者下个准备阶段开始前移除其铁盾贡献；若该角色仍在场且未淘汰，永久启用鲜血诅咒。每个自己的回合第一次合法指定目标并实际支付【杀】后，对第一名合法指定目标先造成场地普通伤害2，再继续杀无效和原攻击。

## 二、攻击挂起与续算

鲜血诅咒发生在费用支付后、杀无效检查前。服务端把已支付攻击保存为一次即时续算，不提前创建正式攻击上下文：

1. 原子支付【杀】与攻击次数，并关闭出牌窗口；
2. 消耗本回合鲜血诅咒额度；
3. 通过共享直接伤害管线结算场地普通伤害2；
4. 若目标濒死，先完整完成救援、死亡、淘汰及胜负检查；
5. 第一目标不再合法时取消原攻击，已付费用不退且武器蓄力不清零；
6. 目标仍合法时才检查盾牌/圆盾等杀无效；未被无效才清蓄力、消费必暴授权并创建标准攻击上下文。

这样保证了“鲜血诅咒先于杀无效”，同时不会让濒死流程与尚未正式发起的攻击上下文互相占用权威窗口。

## 三、持续期隔离修正

准备阶段到期钩子按来源标记精确删除持续期。号角小队、鲜血祭坛、圆盾和幽灵王冠不会再因为共享 `owner.nextPhase.prepare.before` 到期点而误删彼此或其他效果。

鲜血祭坛记录本次把铁盾提升到最低1所贡献的数值；到期只移除该贡献。使用前已经高于1的铁盾不会被祭坛制造，也不会在到期时被错误扣除。
