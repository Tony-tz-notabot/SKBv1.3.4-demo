# 精灵伤害来源瞄准与攻击次数豁免

## 一、伤害来源记录

- 一次攻击对精灵的当前目标全部伤害段完成后，以`attack.target.after.actualHpLoss`判断是否建立瞄准。
- 只有实际血量损失大于0才记录；仅损失护盾、特殊生命层、0伤、免疫或修改数值均不记录。
- 标记值是造成该次攻击的角色引用。后发生的合格来源覆盖旧来源；来源之后死亡不回溯清除该稳定引用。
- 多目标攻击仍按每个目标的完整汇总依次处理，不从单个中间伤害段提前更新。

## 二、瞄准攻击费用

攻击报价新增：

- `attackCountWaivedTargetRef`：当前合法瞄准目标；
- `attackCountCostWithoutAim`：不采用瞄准时的实际次数费用；
- `attackCountCost`：报价中存在合法瞄准目标时的最低可支付次数。

提交时按最终目标集合再次判断。包含瞄准目标才把攻击次数费用改为0；选择其他目标仍按普通规则或号角小队规则支付。因此，客户端不能借一个0次数报价改选其他角色。

瞄准只改攻击次数费用，不改变以下边界：

- 必须使用当前预选的合法武器或合法手刀；
- 仍需支付攻击模式要求的【杀】；
- 仍需通过射程、目标数、在场状态和杀无效等检查；
- 不可据此更换武器。

## 三、解除节点

精灵作为攻击者对当前瞄准目标的一次攻击实际造成正数血量损失后，在该目标`attack.target.after`节点移除瞄准。仅命中、仅扣盾或0实际扣血不会解除。

## 四、验证

行为测试覆盖实际扣血建立、盾伤不覆盖、后来源覆盖、0剩余次数攻击瞄准目标、换目标拒绝、【杀】支付、手刀预选以及对瞄准目标扣血后解除。服务端全量70个测试文件、302项测试通过，TypeScript生产构建通过。
