# SKB v1.3.4通用规则测试清单

状态：正式稿配套验收清单。规则来源：`01-统一规则总纲.md`。

每个测试至少记录：规则版本、初始公开状态、隐藏牌序、输入命令、随机结果、事件序列、最终状态和各玩家可见视图。

## 一、回合与顺序

| ID | 场景 | 必须验证 |
| --- | --- | --- |
| G001 | 四人普通轮转 | 座位按1→2→3→4→1逆时针行动 |
| G002 | 单个阶段被跳过 | 不产生该阶段开始、阶段内、阶段结束事件 |
| G003 | 即将进入阶段的替代 | 替代效果在阶段跳过前仍可触发 |
| G004 | 多目标同时受效果 | 逆时针逐个目标完整处理，含每人的濒死 |
| G005 | 普通同窗触发 | 按逆时针逐项结算，不错误使用响应栈 |
| G006 | 明确响应嵌套 | 后进先出；圣骑士雕像可连续反制 |

## 三、装备、合成与BOSS槽

| ID | 场景 | 必须验证 |
| --- | --- | --- |
| G013 | 主动丢弃装备 | 自己出牌阶段合法，触发失去装备并按规则离场 |
| G014 | 装备区失效 | 牌留槽、状态保留、效果关闭；BOSS和初始天赋不受影响 |
| G015 | 第三武器泛武器效果 | 传递、拆除、熔炉等均包含第三武器 |
| G016 | 合成材料来自装备区 | 触发失去装备但不视为弃置；产物进入手牌 |

| G018 | BOSS槽已有普通持续BOSS | 新持续BOSS使用非法；即时BOSS仍可使用 |
| G019 | 钢铁破浪者号被替换 | 自己出牌阶段可被新持续BOSS替换 |
| G020 | BOSS泛称拆除开关 | `true`可选BOSS；`false`不可选；两条分支均通过 |

## 四、攻击、响应与伤害

| ID | 场景 | 必须验证 |
| --- | --- | --- |
| G021 | 未预选有效武器 | 只提示选择，不支付杀和次数，不创建攻击 |
| G022 | 空槽与手刀 | 全部武器槽为空才有效；有失效武器也不能手刀 |
| G023 | 杀被盾牌/圆盾无效 | 杀和次数已消耗，攻击未发起，蓄力和号角保留 |
| G024 | 多段攻击出闪 | 默认一次闪抵消全部段，攻击未命中 |
| G025 | 多段远程近战格挡 | 一次格挡抵消全部段，攻击未命中 |
| G026 | 激光响应 | 可闪、不可近战格挡；防具除非被破除仍可处理 |
| G027 | 场地攻击 | 不可闪、不可近战格挡、无视防具；非防具无效仍可生效 |
| G028 | 0伤命中 | 命中事件存在，不产生实际伤害或伤害收益 |
| G029 | 有判定武器暴击 | 判中视为暴击；必定暴击可指定成功结果 |
| G030 | 无判定武器暴击 | 每个非附加段+1，附加/效果伤害不加 |
| G031 | 火毒双元素 | 火、毒免疫和加成分别处理，可各自减免/增加 |
| G032 | 蓝盾多段 | 每段开始时独立检查是否仍有护盾 |
