# 道士反弹参数与十层截断复核

状态：R015、R016严格执行证据闭环。

## 一、执行结论

- 只有道士令远程攻击未命中时才创建乾坤挪移反弹；近战攻击未命中不创建。
- 鬼王冠等令攻击无效的防具效果不是闪避，不创建反弹。
- 反弹复制原攻击尚未结算的武器、模式、攻击类型、响应规则和伤害段；清除当前目标临时结果、原后续队列、已支付【杀】和出牌窗口恢复信息。
- 反弹攻击保持原攻击者为攻击/伤害来源，并以原攻击者自身为新目标；道士只记录为反弹发起角色，不替换伤害来源。
- 新攻击不支付【杀】或攻击次数，被反弹目标进入正常响应管线。
- `chainDepth`从1递增至10；深度10的攻击再次未命中时不再创建深度11攻击。

## 二、验证

既有攻击调度测试已覆盖反弹进入真实响应窗口。本轮补强快照断言，明确验证原攻击者来源、原攻击者新目标、攻击类型/伤害段保留、费用清空、反弹角色归属、近战不触发以及第10层截断。

本项不改变规则数值或既有正式裁定。
