# 狼人笔记五色费用与死亡笔记复用

## 一、规则边界

- 狼人笔记只在狼人自己的出牌阶段开放，整局最多成功使用2次。
- 费用必须是手牌中的白、绿、蓝、橙、红各1张；五张牌必须是不同实例，装备区或其他区域的牌不合法。
- 提交时按“重验目标与费用→弃置五色手牌→血量上限+1并回复1血→执行死亡笔记”结算。
- 死亡笔记根据执行时目标状态分支：护盾大于0则修改护盾为0，否则修改血量为1。
- 两种修改均不是伤害，不产生受伤、破盾伤害或濒死流程；费用支付完成后，目标效果即使成为空操作也不返还狼人收益。

## 二、实现复用

普通特殊牌死亡笔记原有逻辑已抽成事务内`applyDeathNoteInTransaction`原语。实体死亡笔记与狼人笔记共用同一分支和事件语义，区别仅在来源引用与前置费用/收益，避免两条路径以后产生规则偏差。

`WerewolfNotebookSession`负责：

- 按冻结卡牌事实生成每种颜色的合法手牌集合；
- 服务器权威重验五种颜色、不同实例、在场目标和整局次数；
- 原子弃牌、属性变化、目标修改和使用计数；
- 修订、优先权、报价与命令幂等校验。

## 三、验证

行为测试覆盖有盾分支、无盾/负血量修改分支、修改不触发伤害或濒死、两次整局上限、重复颜色拒绝及失败零污染。服务端全量68个测试文件、296项测试通过，TypeScript生产构建通过。
