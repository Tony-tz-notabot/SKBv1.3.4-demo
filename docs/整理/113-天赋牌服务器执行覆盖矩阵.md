# 天赋牌服务器执行覆盖矩阵

## 严格口径与共同边界

仅有冻结 DSL 不算闭环，必须存在生效来源识别、真实事件入口、执行或报价边界和行为测试。初始天赋不受一般装备失效影响；装备区天赋同时受失效标记与失效状态控制。

- 已实现出牌阶段装备、同名（含初始天赋）非法失去并摸一、装备区天赋主动丢弃。
- 血量、护盾、手牌上限贡献从冻结 nonboss-rules.json 解析并保存为装备实例快照；失效、恢复、离场使用同一快照。
- 装备移动统一产生失牌事实；初始天赋不占区域、不可拆除。
