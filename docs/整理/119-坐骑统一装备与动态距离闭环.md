# 坐骑统一装备与动态距离闭环

状态：服务端权威实现完成。规则来源为《v1.3.4非BOSS牌规则正文》、第四轮正式裁定及冻结 `nonboss-rules.json`。

## 实现范围

- M-01—M-11 共11张坐骑统一经过 `mountEquipment.ts` 报价、幂等装备、主动丢弃和替换流程。
- `+`、`-`、`±` 的占槽由冻结 `occupiedSlots` 读取；双槽坐骑仅保留一个卡牌实例，以运行时占槽快照声明两槽。任一需求槽冲突时，原双槽坐骑整张离场并一次释放全部占槽。
- 静态攻防距离值由 `distanceModifier` 读取并写入装备实例快照；所有调用统一 `calculateEffectiveDistance` 的距离检查自动生效，距离不限仍不读取有效距离。
- 百变怪与同类坐骑共用同一装备/替换处理器，只增加距离计算时的动态天赋查询：火盾、毒盾分别令进攻距离-1，冰盾、电盾分别令防御距离+1；初始天赋计入，装备整体失效时坐骑及普通装备天赋贡献均关闭。
- 最终有效距离继续使用全局最低0规则；坐骑不修改基础座位环和淘汰移位。

## 权威边界

- 客户端只提交服务器报价中的卡牌实例及报价ID，不自行推算替换对象或距离。
- 所有数值、槽位和替换策略来自版本化规则集；业务代码只解释字段语义。
- 双槽占用不复制卡牌实例，避免同一卡牌同时存在于两个区域而破坏状态不变量。
