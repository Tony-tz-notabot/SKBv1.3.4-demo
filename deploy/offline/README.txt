SKB v1.3.4 联机游戏 · 客户端离线包使用说明
============================================

本目录是游戏客户端离线包：界面与全部卡牌图片都在本机运行，
对局数据（房间/选角/出牌/胜负）通过云服务器同步，客户端自身
只消耗很小的游戏消息流量（不下载任何图片/页面资源）。

一、启动（Windows）
  1. 解压本目录到任意位置；
  2. 双击「启动客户端.bat」；
  3. 浏览器自动可访问（若未自动打开）：http://localhost:8080

二、启动（macOS / Linux）
  终端执行：
    chmod +x 启动客户端.command
    ./启动客户端.command
  然后浏览器打开 http://localhost:8080

三、首次使用
  1. 打开页面后先注册账号（用户名 + 密码，自动注册）；
  2. 创建房间，把房间号告诉其他玩家（房间页右上角有复制按钮）；
  3. 其他玩家同样打开本离线包 → 登录 → 输入房间号加入。

四、注意事项
  - 需要本机已安装 Node.js（20 以上，nodejs.org 下载）。
  - 本包不包含服务器，对局数据保存在云端；
  - 每次游戏需要保持本窗口开启，关掉后页面关闭、需重新登录；
  - 更新客户端：向服务商索取新包替换即可。
